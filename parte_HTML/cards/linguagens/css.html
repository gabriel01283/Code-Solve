CSS

CSS é a linguagem usada para estilizar páginas web. Enquanto o HTML cria a estrutura do conteúdo, o CSS define a aparência visual da página, como cores, tamanhos, fontes, espaçamentos, alinhamentos, bordas, animações e layouts.

Sem CSS, uma página HTML até funciona, mas fica visualmente simples e sem identidade. Com CSS, é possível transformar a estrutura da página em uma interface bonita, organizada, responsiva e agradável para o usuário.

O que é CSS?

CSS significa Cascading Style Sheets, ou Folhas de Estilo em Cascata. Ele é usado para aplicar estilos aos elementos HTML.

O termo “cascata” significa que as regras de estilo seguem uma ordem de prioridade. Dependendo de onde e como uma regra é escrita, ela pode sobrescrever outra. 


p {
    color: blue;
    font-size: 18px;
}

Para que serve CSS?

  • Definir cores
  • Alterar fontes
  • Controlar tamanhos
  • Organizar layouts
  • Criar espaçamentos
  • Estilizar botões
  • Criar cards
  • Fazer páginas responsivas
  • Criar animações
  • Melhorar a experiência visual do usuário

Como conectar CSS ao HTML

A forma mais comum de usar CSS é criar um arquivo separado e conectá-lo ao HTML usando a tag <link> dentro do <head>. 


<link rel="stylesheet" href="style.css">

Isso mantém a estrutura da página separada do estilo, deixando o projeto mais organizado.

Seletores

Seletores indicam quais elementos HTML receberão determinado estilo.

Seletor por tag


p {
    color: white;
}

Seletor por classe


.card {
    background-color: #111827;
}

Seletor por id


#titulo {
    font-size: 32px;
}

Classes e IDs

Classes são usadas quando queremos aplicar o mesmo estilo em vários elementos. IDs são usados para identificar um elemento único na página. 


<h1 id="titulo-principal">Meu site</h1>

<div class="card">Conteúdo</div>
<div class="card">Outro conteúdo</div>
            

#titulo-principal {
    color: cyan;
}

.card {
    border-radius: 12px;
}

Cores

CSS permite definir cores de várias formas: por nome, hexadecimal, RGB, RGBA, HSL e HSLA. 


h1 {
    color: cyan;
}

p {
    color: #ffffff;
}

.card {
    background-color: rgba(255, 255, 255, 0.1);
}

Fontes e textos

CSS permite controlar a aparência dos textos da página. 


p {
    font-family: Arial, sans-serif;
    font-size: 18px;
    font-weight: 400;
    line-height: 1.6;
    text-align: left;
}
  • font-family: define a fonte
  • font-size: define o tamanho do texto
  • font-weight: define o peso da fonte
  • line-height: define a altura da linha
  • text-align: define o alinhamento

Box Model

Todo elemento HTML pode ser visto como uma caixa. Essa caixa possui conteúdo, preenchimento interno, borda e margem externa.

  • content: conteúdo do elemento
  • padding: espaço interno
  • border: borda do elemento
  • margin: espaço externo

.card {
    padding: 20px;
    border: 1px solid #ffffff;
    margin: 16px;
}

Box-sizing

Uma prática comum em CSS é usar box-sizing: border-box. Isso faz com que padding e border sejam considerados dentro do tamanho total do elemento. 


* {
    box-sizing: border-box;
}

Display

A propriedade display define como um elemento se comporta no layout. 


div {
    display: block;
}

span {
    display: inline;
}

.container {
    display: flex;
}
  • block: ocupa uma linha inteira
  • inline: ocupa apenas o espaço do conteúdo
  • flex: cria layout flexível
  • grid: cria layout em grade
  • none: esconde o elemento

Flexbox

Flexbox é uma ferramenta poderosa para organizar elementos em linha ou coluna. Ele facilita alinhamentos e distribuições de espaço. 


.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}
  • justify-content: alinha no eixo principal
  • align-items: alinha no eixo transversal
  • gap: define espaço entre elementos
  • flex-direction: define linha ou coluna

CSS Grid

CSS Grid é usado para criar layouts em linhas e colunas. É muito útil para cards, galerias, áreas principais e estruturas mais complexas. 


.cards-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 24px;
}

Position

A propriedade position controla como um elemento é posicionado na página.

  • static: posição padrão
  • relative: permite deslocar o elemento em relação à posição original
  • absolute: posiciona em relação a um ancestral posicionado
  • fixed: fixa na tela
  • sticky: fixa em determinado ponto durante a rolagem

nav {
    position: sticky;
    top: 0;
}

Responsividade

Responsividade é a capacidade da página se adaptar a diferentes tamanhos de tela, como computador, tablet e celular.

Para isso, usamos medidas flexíveis, layouts adaptáveis e media queries. 


@media (max-width: 768px) {
    .container {
        flex-direction: column;
    }
}

Unidades de medida

CSS possui várias unidades para definir tamanhos.

  • px: pixels, medida fixa
  • %: porcentagem em relação ao elemento pai
  • em: relativa ao tamanho da fonte do elemento
  • rem: relativa ao tamanho da fonte raiz
  • vw: porcentagem da largura da tela
  • vh: porcentagem da altura da tela

main {
    width: 90%;
    max-width: 1100px;
    min-height: 100vh;
}

Transições

Transições suavizam mudanças de estilo, como cor, tamanho, sombra ou posição. 


button {
    transition: 0.3s;
}

button:hover {
    transform: translateY(-2px);
}

Hover

O :hover aplica estilos quando o usuário passa o mouse sobre um elemento. 


.card:hover {
    transform: scale(1.03);
    border-color: cyan;
}

Animações

CSS permite criar animações usando @keyframes. 


@keyframes aparecer {
    from {
        opacity: 0;
        transform: translateY(20px);
    }

    to {
        opacity: 1;
        transform: translateY(0);
    }
}

.card {
    animation: aparecer 0.5s ease;
}

Pseudoclasses

Pseudoclasses aplicam estilos em estados específicos dos elementos. 


a:hover {
    color: cyan;
}

input:focus {
    border-color: blue;
}

li:first-child {
    font-weight: bold;
}

Pseudoelementos

Pseudoelementos permitem estilizar partes específicas de um elemento. 


p::first-letter {
    font-size: 32px;
}

.card::before {
    content: "";
    display: block;
}

Variáveis CSS

Variáveis CSS permitem armazenar valores reutilizáveis, como cores e tamanhos. 


:root {
    --cor-principal: #00eaff;
    --fundo-card: #111827;
}

.card {
    background-color: var(--fundo-card);
    color: var(--cor-principal);
}

z-index

O z-index controla a ordem de sobreposição dos elementos. Ele funciona em elementos posicionados. 


nav {
    position: fixed;
    z-index: 10;
}

Blur e backdrop-filter

O backdrop-filter permite criar efeitos visuais modernos, como blur em fundos transparentes. 


.card {
    background: rgba(255, 255, 255, 0.08);
    backdrop-filter: blur(18px);
}

Esse efeito é muito usado em interfaces modernas, futuristas e minimalistas.

Boas práticas em CSS

  • Separar CSS em arquivos próprios
  • Usar nomes de classes claros
  • Evitar repetir estilos sem necessidade
  • Organizar o código por seções
  • Usar comentários simples para dividir áreas
  • Usar responsividade desde o começo
  • Evitar excesso de IDs para estilização
  • Manter consistência de cores, fontes e espaçamentos

Erros comuns de iniciantes

Errar o caminho do CSS

Se o caminho no link estiver errado, o CSS não será carregado.

Confundir class com id

Classes usam ponto no CSS. IDs usam hashtag. 


.card {
    color: white;
}

#titulo {
    color: cyan;
}

Esquecer unidades

Em propriedades como width, margin e padding, normalmente é necessário usar unidades como px, %, rem ou vh.

Não pensar em responsividade

Uma página pode ficar bonita no computador e quebrada no celular se não houver cuidado com responsividade.

Exemplo simples de CSS


* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

body {
    font-family: Arial, sans-serif;
    background: #050816;
    color: #ffffff;
}

.card {
    padding: 24px;
    border-radius: 16px;
    background: rgba(255, 255, 255, 0.08);
    border: 1px solid rgba(255, 255, 255, 0.12);
    backdrop-filter: blur(18px);

}

.card:hover {
    transform: translateY(-4px);
    border-color: #00eaff;
}

Dúvidas comuns sobre CSS

CSS é linguagem de programação?

Não no sentido tradicional. CSS é uma linguagem de estilo usada para definir a aparência de páginas HTML.

Preciso aprender HTML antes de CSS?

Sim. CSS estiliza elementos HTML, então entender HTML ajuda muito.

CSS serve para criar lógica?

CSS não é usado para lógica de aplicação. Para comportamento e interatividade, usamos JavaScript.

Flexbox ou Grid?

Flexbox é ótimo para alinhamentos em uma direção. Grid é melhor para layouts em linhas e colunas.

CSS ainda é usado com frameworks?

Sim. Mesmo usando React, Vue, Angular ou Next.js, o estilo visual ainda depende de CSS ou ferramentas baseadas nele.

Resumo

CSS é a tecnologia responsável pelo visual das páginas web. Ele controla cores, fontes, tamanhos, espaçamentos, layouts, responsividade, animações e efeitos visuais.

Seus principais conceitos incluem seletores, classes, IDs, box model, flexbox, grid, position, responsividade, media queries, transições, animações e boas práticas de organização.
