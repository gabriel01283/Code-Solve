Java

Java é uma linguagem de programação muito usada no desenvolvimento de sistemas, aplicações web, aplicativos Android, sistemas corporativos, APIs, jogos, aplicações desktop e soluções empresariais.

A linguagem ficou conhecida por sua portabilidade, organização e forte uso da programação orientada a objetos. O lema mais famoso associado ao Java é: escreva uma vez, execute em qualquer lugar.

Java é uma linguagem muito presente no mercado de trabalho, principalmente em empresas, bancos, sistemas grandes e aplicações que precisam de estabilidade.

O que é Java?

Java é uma linguagem de programação de alto nível, compilada para bytecode, fortemente tipada, estaticamente tipada e orientada a objetos.

O código Java é compilado para um formato intermediário chamado bytecode. Esse bytecode é executado pela JVM, a Máquina Virtual Java. 


public class Main {
    public static void main(String[] args) {
        System.out.println("Olá, mundo!");
    }
}

Para que serve Java?

  • Desenvolvimento backend
  • Criação de APIs REST
  • Sistemas corporativos
  • Aplicativos Android
  • Aplicações desktop
  • Sistemas bancários
  • Microsserviços
  • Jogos
  • Aplicações com banco de dados

O que é JVM?

JVM significa Java Virtual Machine. Ela é responsável por executar o bytecode gerado pelo compilador Java.

Isso permite que um programa Java funcione em diferentes sistemas operacionais, desde que exista uma JVM instalada.

Essa característica torna Java uma linguagem muito portátil.

Java é compilada ou interpretada?

Java passa por um processo de compilação para bytecode e depois esse bytecode é executado pela JVM.

Por isso, Java não é interpretada da mesma forma que Python. Ela tem uma etapa de compilação antes da execução. 


javac Main.java
java Main

Tipagem

Java é uma linguagem estaticamente tipada e fortemente tipada.

Isso significa que os tipos das variáveis precisam ser conhecidos em tempo de compilação e que Java evita misturar tipos incompatíveis sem conversão. 


String nome = "Gabriel";
int idade = 20;
double altura = 1.75;
boolean ativo = true;

Variáveis

Variáveis armazenam valores na memória. Em Java, precisamos declarar o tipo da variável antes de usá-la. 


String nome = "Gabriel";
int idade = 20;

System.out.println(nome);
System.out.println(idade);

Tipos primitivos

int

Representa números inteiros.


int idade = 20;
System.out.println(idade);

double

Representa números decimais com maior precisão.


double altura = 1.75;
System.out.println(altura);

float

Representa números decimais com menor precisão que double.


float preco = 19.99f;
System.out.println(preco);

char

Representa um único caractere.


char letra = 'A';
System.out.println(letra);

boolean

Representa verdadeiro ou falso.


boolean ativo = true;
System.out.println(ativo);

String

String representa textos em Java. Diferente dos tipos primitivos, String é uma classe. 


String nome = "Gabriel";
String linguagem = "Java";

System.out.println(nome + " estuda " + linguagem);

Condicionais

Condicionais permitem executar blocos diferentes dependendo de uma condição. 


int idade = 18;

if (idade >= 18) {
    System.out.println("Maior de idade");
} else {
    System.out.println("Menor de idade");
}

Switch

O switch é usado para comparar um valor com várias possibilidades. 


String linguagem = "Java";

switch (linguagem) {
    case "Java":
        System.out.println("Linguagem muito usada no backend");
        break;

    case "Python":
        System.out.println("Linguagem muito usada em dados");
        break;

    default:
        System.out.println("Outra linguagem");
}

Laços de repetição

for


for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

while


int contador = 0;

while (contador < 5) {
    System.out.println(contador);
    contador++;
}

do while


int numero = 0;

do {
    System.out.println(numero);
    numero++;
} while (numero < 5);

Arrays

Arrays armazenam vários valores do mesmo tipo em uma única estrutura. 


String[] linguagens = {"Java", "Python", "JavaScript"};

System.out.println(linguagens[0]);

A primeira posição de um array é o índice zero.

ArrayList

ArrayList é uma estrutura mais flexível que arrays tradicionais. Ela permite adicionar e remover elementos com mais facilidade. 


import java.util.ArrayList;

ArrayList<String> linguagens = new ArrayList<>();

linguagens.add("Java");
linguagens.add("Python");

System.out.println(linguagens);

Métodos

Em Java, funções geralmente são chamadas de métodos, principalmente quando estão dentro de classes. 


public static int somar(int a, int b) {
    return a + b;
}

Métodos ajudam a organizar o código e evitar repetição.

Classes e objetos

Java é fortemente baseada em programação orientada a objetos. Classes são modelos usados para criar objetos. 


public class Usuario {
    String nome;
    int idade;
}
            

Usuario usuario = new Usuario();

usuario.nome = "Gabriel";
usuario.idade = 20;

System.out.println(usuario.nome);

Construtores

Construtores são métodos especiais executados quando um objeto é criado. Eles servem para inicializar os atributos do objeto. 


public class Usuario {
    String nome;
    int idade;

    public Usuario(String nome, int idade) {
        this.nome = nome;
        this.idade = idade;
    }
}

this

A palavra-chave this representa o próprio objeto atual. Ela é muito usada para diferenciar atributos da classe de parâmetros. 


public Usuario(String nome) {
    this.nome = nome;
}

Encapsulamento

Encapsulamento é o princípio de proteger os dados internos de uma classe. Em Java, é comum usar atributos privados e métodos públicos de acesso. 


public class Usuario {
    private String nome;

    public String getNome() {
        return nome;
    }

    public void setNome(String nome) {
        this.nome = nome;
    }
}

Os métodos get e set permitem acessar e alterar os atributos de forma controlada.

Herança

Herança permite que uma classe aproveite características de outra classe. 


public class Pessoa {
    String nome;
}

public class Aluno extends Pessoa {
    String turma;
}

Nesse exemplo, Aluno herda o atributo nome da classe Pessoa.

Polimorfismo

Polimorfismo permite que um mesmo método ou referência tenha comportamentos diferentes dependendo do objeto usado. 


class Animal {
    void emitirSom() {
        System.out.println("Som genérico");
    }
}

class Cachorro extends Animal {
    void emitirSom() {
        System.out.println("Latido");
    }
}

Interfaces

Interfaces definem contratos que classes devem seguir. 


interface Autenticavel {
    void login();
}

class Usuario implements Autenticavel {
    public void login() {
        System.out.println("Usuário logado");
    }
}

Tratamento de exceções

Java usa exceções para lidar com erros durante a execução. 


try {
    int resultado = 10 / 0;
} catch (ArithmeticException erro) {
    System.out.println("Erro: divisão por zero");
}

Pacotes

Pacotes organizam classes em grupos. Eles ajudam a manter projetos maiores mais estruturados. 


package usuarios;

public class Usuario {
}

Maven e Gradle

Maven e Gradle são ferramentas usadas para gerenciar dependências, compilar projetos e automatizar tarefas em aplicações Java.

Em projetos profissionais, é comum usar uma dessas ferramentas para organizar bibliotecas externas e o processo de build.

Java no backend com Spring Boot

Spring Boot é um dos frameworks mais usados para criar aplicações backend com Java. Ele facilita a criação de APIs REST, autenticação, integração com banco de dados e sistemas corporativos. 


@RestController
public class HomeController {

    @GetMapping("/")
    public String home() {
        return "API funcionando";
    }
}

Java no Android

Java foi por muitos anos uma das principais linguagens para desenvolvimento Android. Atualmente Kotlin é muito usado nessa área, mas Java ainda aparece em muitos projetos antigos e aplicações existentes.

Onde Java é usado?

  • APIs backend
  • Sistemas corporativos
  • Aplicações bancárias
  • Aplicativos Android
  • Microsserviços
  • Aplicações desktop
  • Sistemas com Spring Boot
  • Processamento de dados

Vantagens do Java

  • Muito usado no mercado
  • Forte em sistemas corporativos
  • Boa portabilidade com JVM
  • Grande ecossistema de bibliotecas
  • Boa organização com orientação a objetos
  • Spring Boot é muito usado no backend
  • Comunidade grande e madura

Desvantagens do Java

  • Sintaxe mais verbosa que linguagens como Python e Kotlin
  • Pode parecer burocrático para iniciantes
  • Exige entender bem orientação a objetos
  • Projetos grandes podem ficar complexos sem boa organização

Boas práticas em Java

  • Usar nomes claros para classes, métodos e variáveis
  • Manter classes com responsabilidades bem definidas
  • Usar encapsulamento com atributos privados
  • Evitar métodos muito grandes
  • Organizar o código em pacotes
  • Tratar exceções corretamente
  • Evitar repetição de código
  • Usar ferramentas como Maven ou Gradle em projetos maiores

Erros comuns de iniciantes

Esquecer ponto e vírgula

Em Java, muitas instruções precisam terminar com ponto e vírgula.

Confundir classe com objeto

Classe é o modelo. Objeto é a instância criada a partir desse modelo.

Não entender static

A palavra-chave static indica que algo pertence à classe, e não a um objeto específico.

Não usar encapsulamento

Deixar todos os atributos públicos pode prejudicar a segurança e a manutenção do código.

Exemplo simples em Java


public class Usuario {
    private String nome;
    private int idade;

    public Usuario(String nome, int idade) {
        this.nome = nome;
        this.idade = idade;
    }

    public String verificarIdade() {
        if (idade >= 18) {
            return "Maior de idade";
        }

        return "Menor de idade";
    }

    public void apresentar() {
        System.out.println("Nome: " + nome);
        System.out.println("Idade: " + idade);
        System.out.println(verificarIdade());
    }

    public static void main(String[] args) {
        Usuario usuario = new Usuario("Gabriel", 20);

        usuario.apresentar();
    }
}

Dúvidas comuns sobre Java

Java é bom para iniciantes?

Sim, mas pode parecer mais difícil no começo por causa da orientação a objetos e da sintaxe mais extensa.

Java é a mesma coisa que JavaScript?

Não. Java e JavaScript são linguagens diferentes.

Java ainda é usado?

Sim. Java continua muito usado em empresas, sistemas corporativos, backend e aplicações com Spring Boot.

Java serve para backend?

Sim. Java é uma das linguagens mais usadas no backend, principalmente com Spring Boot.

Vale a pena aprender Java?

Sim, principalmente para quem deseja trabalhar com backend, sistemas corporativos, Android legado ou aprender bem programação orientada a objetos.

Resumo

Java é uma linguagem robusta, madura e muito usada no mercado. Ela é forte em backend, sistemas corporativos, aplicações Android antigas e projetos que exigem organização e estabilidade.

Seus principais conceitos incluem variáveis, tipos, condicionais, loops, arrays, métodos, classes, objetos, construtores, encapsulamento, herança, polimorfismo, interfaces, exceções e uso da JVM.
