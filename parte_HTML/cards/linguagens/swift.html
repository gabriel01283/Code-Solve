Swift

Swift é uma linguagem de programação moderna criada pela Apple para desenvolver aplicativos seguros, rápidos e fáceis de manter. Ela é muito usada no desenvolvimento de aplicativos para iPhone, iPad, Mac, Apple Watch, Apple TV e outros produtos do ecossistema Apple.

A linguagem foi projetada para ser mais simples e segura do que Objective-C, que era muito usada anteriormente no desenvolvimento para plataformas Apple. Swift possui uma sintaxe mais moderna, recursos de segurança contra erros comuns e bom desempenho.

Mesmo sendo muito associada ao desenvolvimento mobile, Swift também pode ser usada em outras áreas, como backend, scripts, ferramentas de linha de comando e aplicações multiplataforma.

O que é Swift?

Swift é uma linguagem de programação compilada, de alto nível, fortemente tipada e multiparadigma. Ela combina recursos de linguagens modernas com desempenho próximo de linguagens mais tradicionais.

O principal objetivo de Swift é permitir que desenvolvedores criem aplicações eficientes com uma sintaxe clara e segura. A linguagem tenta evitar erros comuns de programação, como uso incorreto de valores nulos, conversões perigosas de tipos e acesso inseguro à memória.

Swift é muito utilizada junto com ferramentas como Xcode, SwiftUI e UIKit para criar interfaces e aplicativos completos dentro do ecossistema Apple.

Para que serve Swift?

Swift serve principalmente para desenvolver aplicativos para plataformas Apple. Ela é a linguagem mais usada atualmente para criar apps modernos para iOS, macOS, watchOS, tvOS e visionOS.

  • Aplicativos para iPhone
  • Aplicativos para iPad
  • Aplicativos para Mac
  • Aplicativos para Apple Watch
  • Aplicativos para Apple TV
  • Aplicações com SwiftUI
  • Aplicações com UIKit
  • Ferramentas de linha de comando
  • Backend com frameworks como Vapor

Nível da linguagem

Swift é considerada uma linguagem de alto nível, porque possui uma sintaxe próxima da forma humana de pensar e oferece recursos que facilitam a criação de programas complexos.

Mesmo sendo de alto nível, Swift também é uma linguagem performática. Ela é compilada e foi criada para entregar boa velocidade em aplicações reais.

Essa combinação torna Swift uma linguagem adequada para aplicativos modernos, com interface gráfica, acesso a banco de dados, comunicação com APIs, animações, sensores, notificações e outras funcionalidades comuns em apps.

Swift é compilada ou interpretada?

Swift é uma linguagem compilada. Isso significa que o código escrito pelo desenvolvedor é transformado em instruções executáveis antes de rodar no dispositivo.

A compilação ajuda a melhorar o desempenho e também permite que muitos erros sejam encontrados antes da execução do programa. 


print("Olá, mundo!")

Esse é um exemplo simples de código Swift. A função print exibe uma mensagem na saída do programa.

Tipagem

Swift é uma linguagem estaticamente tipada e fortemente tipada.

Ser estaticamente tipada significa que os tipos das variáveis são verificados antes da execução do programa, durante a compilação.

Ser fortemente tipada significa que Swift evita misturar tipos de forma perigosa. Por exemplo, ela não trata automaticamente um texto como número sem que o programador faça uma conversão explícita.

Swift também possui inferência de tipos. Isso significa que, em muitos casos, o compilador consegue descobrir o tipo de uma variável automaticamente. 


let nome = "Gabriel"
let idade = 20
let ativo = true

Nesse exemplo, Swift consegue entender que nome é uma String, idade é um número inteiro e ativo é um valor booleano.

let e var

Em Swift, usamos let para criar constantes e var para criar variáveis.

let

O let cria um valor que não pode ser alterado depois de definido. É usado quando sabemos que aquele dado não precisa mudar. 


let nome = "Gabriel"
print(nome)

var

O var cria um valor que pode ser alterado depois. 


var idade = 20
idade = 21

print(idade)

Uma boa prática em Swift é usar let sempre que possível e usar var apenas quando o valor realmente precisar mudar.

Tipos primitivos

Int

Representa números inteiros, ou seja, números sem casas decimais. 


let idade: Int = 20
print(idade)

Double

Representa números com casas decimais e maior precisão. 


let altura: Double = 1.75
print(altura)

Float

Também representa números decimais, mas com menor precisão do que Double. 


let preco: Float = 19.99
print(preco)

Bool

Representa valores lógicos: verdadeiro ou falso. 


let usuarioAtivo: Bool = true
print(usuarioAtivo)

Character

Representa um único caractere. 


let letra: Character = "A"
print(letra)

String

Representa textos, ou seja, sequências de caracteres. 


let linguagem: String = "Swift"
print(linguagem)

Strings em Swift

Strings são usadas para armazenar textos. Em Swift, uma String pode conter letras, números, espaços, símbolos e caracteres especiais. 


let nome = "Gabriel"
let sobrenome = "Saraiva"

let nomeCompleto = nome + " " + sobrenome

print(nomeCompleto)

Swift também permite interpolação de strings, que é uma forma prática de colocar valores dentro de um texto. 


let nome = "Gabriel"
let idade = 20

print("Meu nome é \(nome) e tenho \(idade) anos.")

Arrays

Arrays são estruturas usadas para armazenar vários valores em uma única variável. Em Swift, os valores de um array normalmente possuem o mesmo tipo. 


var linguagens = ["Swift", "Python", "JavaScript"]

print(linguagens[0])

Também é possível adicionar novos elementos ao array. 


linguagens.append("Java")

print(linguagens)

Dictionaries

Dictionaries armazenam dados no formato chave e valor. Eles são úteis quando queremos associar uma informação a uma chave específica. 


let usuario = [
    "nome": "Gabriel",
    "email": "gabriel@email.com"
]

print(usuario["nome"]!)

Nesse exemplo, a chave nome está associada ao valor Gabriel.

Optionals

Optionals são um dos conceitos mais importantes de Swift. Eles representam valores que podem existir ou não.

Em muitas linguagens, o uso incorreto de valores nulos pode causar erros durante a execução. Swift tenta reduzir esse problema usando Optionals. 


var nome: String? = "Gabriel"
print(nome)

O símbolo ? indica que a variável pode conter uma String ou pode não conter valor nenhum.

Optional Binding

Para usar com segurança um valor Optional, é comum utilizar if let. Isso verifica se o valor existe antes de usá-lo. 


var nome: String? = "Gabriel"

if let nomeSeguro = nome {
    print("Nome: \(nomeSeguro)")
} else {
    print("Nome não informado")
}

Esse recurso ajuda a evitar erros causados por tentar acessar um valor inexistente.

Force unwrap

O force unwrap usa o símbolo ! para acessar diretamente o valor dentro de um Optional. 


var nome: String? = "Gabriel"

print(nome!)

Esse recurso deve ser usado com cuidado. Se o Optional não tiver valor, o programa pode quebrar durante a execução.

Por isso, em muitos casos, é melhor usar if let ou guard let.

Funções

Funções são blocos de código reutilizáveis. Elas podem receber dados, executar uma tarefa e retornar um resultado. 


func somar(a: Int, b: Int) -> Int {
    return a + b
}

let resultado = somar(a: 5, b: 3)

print(resultado)

Nesse exemplo, a função recebe dois números inteiros e retorna a soma deles.

Condicionais

Condicionais permitem executar partes diferentes do código dependendo de uma condição. 


let idade = 18

if idade >= 18 {
    print("Maior de idade")
} else {
    print("Menor de idade")
}

Em Swift, a condição precisa resultar em um valor booleano.

Switch

O switch é usado para comparar um valor com vários casos possíveis. Em Swift, ele é muito poderoso e pode ser usado com números, strings, enums e outros tipos. 


let linguagem = "Swift"

switch linguagem {
case "Swift":
    print("Linguagem da Apple")
case "Python":
    print("Linguagem muito usada em dados")
default:
    print("Outra linguagem")
}

Laços de repetição

Laços de repetição permitem executar um bloco de código várias vezes.

for


for numero in 1...5 {
    print(numero)
}

while


var contador = 0

while contador < 5 {
    print(contador)
    contador += 1
}

repeat while


var numero = 0

repeat {
    print(numero)
    numero += 1
} while numero < 5

Structs

Structs são usadas para criar tipos personalizados. Elas agrupam propriedades e comportamentos relacionados. 


struct Usuario {
    let nome: String
    let idade: Int
}

let usuario = Usuario(nome: "Gabriel", idade: 20)

print(usuario.nome)

Structs são muito usadas em Swift, principalmente porque são simples, seguras e eficientes para representar dados.

Classes

Classes também permitem criar tipos personalizados, mas funcionam de forma diferente das structs. Classes trabalham com referência, enquanto structs trabalham com valor. 


class Pessoa {
    var nome: String

    init(nome: String) {
        self.nome = nome
    }
}

let pessoa = Pessoa(nome: "Gabriel")

print(pessoa.nome)

Structs e classes: qual a diferença?

Uma diferença importante é que structs são tipos por valor e classes são tipos por referência.

Quando uma struct é atribuída a outra variável, geralmente ocorre uma cópia do valor. Quando uma classe é atribuída a outra variável, as duas podem apontar para o mesmo objeto.

  • Struct: tipo por valor
  • Class: tipo por referência
  • Struct: muito usada para modelos simples de dados
  • Class: útil quando é necessário compartilhar estado

Enums

Enums permitem representar um conjunto fixo de opções. Eles são muito úteis para estados, categorias e escolhas limitadas. 


enum StatusUsuario {
    case ativo
    case inativo
    case bloqueado
}

let status = StatusUsuario.ativo

Protocols

Protocols definem um conjunto de regras que um tipo deve seguir. Eles são parecidos com interfaces em outras linguagens. 


protocol Apresentavel {
    func apresentar()
}

struct Aluno: Apresentavel {
    let nome: String

    func apresentar() {
        print("Meu nome é \(nome)")
    }
}

Protocols são muito importantes no desenvolvimento Swift e aparecem bastante em projetos com SwiftUI e UIKit.

Extensions

Extensions permitem adicionar funcionalidades a tipos já existentes sem modificar diretamente sua definição original. 


extension String {
    func saudacao() -> String {
        return "Olá, \(self)"
    }
}

let nome = "Gabriel"

print(nome.saudacao())

Closures

Closures são blocos de código que podem ser armazenados em variáveis, passados como argumento para funções ou executados depois. 


let saudacao = {
    print("Olá, mundo!")
}

saudacao()

Closures são muito usadas em Swift, principalmente em eventos, animações, callbacks e programação assíncrona.

Tratamento de erros

Swift possui uma forma própria de lidar com erros usando throw, do, try e catch. 


enum ErroLogin: Error {
    case senhaIncorreta
}

func login(senha: String) throws {
    if senha != "123456" {
        throw ErroLogin.senhaIncorreta
    }
}

do {
    try login(senha: "000000")
} catch {
    print("Erro ao fazer login")
}

Programação assíncrona

Swift possui suporte a programação assíncrona com async e await. Isso é muito útil para tarefas que demoram algum tempo, como chamadas de API, carregamento de arquivos ou acesso à internet. 


func buscarDados() async {
    print("Buscando dados...")
}

Task {
    await buscarDados()
}

Esse modelo ajuda a escrever código assíncrono de forma mais clara e organizada.

SwiftUI

SwiftUI é um framework moderno da Apple para criar interfaces de usuário usando Swift. Ele permite criar telas de forma declarativa, ou seja, descrevendo como a interface deve ser. 


import SwiftUI

struct ContentView: View {
    var body: some View {
        Text("Olá, SwiftUI!")
            .padding()
    }
}

SwiftUI é muito usado em projetos novos para iOS, macOS, watchOS, tvOS e visionOS.

UIKit

UIKit é um framework tradicional da Apple para criar interfaces em aplicativos iOS. Antes do SwiftUI, UIKit era a principal forma de criar telas para iPhone e iPad.

Muitos projetos profissionais ainda usam UIKit, principalmente sistemas mais antigos ou aplicações que precisam de controle mais detalhado sobre a interface.

Xcode

Xcode é o ambiente de desenvolvimento oficial da Apple. Ele é usado para criar, testar, depurar e publicar aplicativos para plataformas Apple.

Com Xcode, o desenvolvedor pode escrever código Swift, criar interfaces, usar simuladores de iPhone e iPad, acompanhar erros e preparar o aplicativo para publicação.

Swift Package Manager

Swift Package Manager é a ferramenta oficial para gerenciar dependências, bibliotecas e pacotes em projetos Swift.

Ele permite adicionar bibliotecas externas, organizar módulos e facilitar a estruturação de projetos maiores.

Swift no backend

Embora Swift seja mais conhecida pelo desenvolvimento de aplicativos Apple, ela também pode ser usada no backend.

Frameworks como Vapor permitem criar APIs, servidores web e aplicações backend usando Swift.

Mesmo assim, Swift no backend é menos comum do que tecnologias como Node.js, Python, Java, C# e Go.

Boas práticas em Swift

Escrever Swift de forma organizada ajuda a manter o projeto mais limpo, seguro e fácil de evoluir.

  • Usar let sempre que o valor não precisar mudar
  • Usar var apenas quando houver necessidade de alteração
  • Evitar force unwrap desnecessário
  • Usar if let ou guard let para lidar com Optionals
  • Dar nomes claros para variáveis, funções e tipos
  • Separar responsabilidades em structs, classes e arquivos diferentes
  • Organizar o código em camadas quando o projeto crescer
  • Evitar funções muito grandes
  • Tratar erros corretamente

Erros comuns de iniciantes

Confundir let e var

Muitos iniciantes usam var para tudo, mas o ideal é usar let quando o valor não precisa ser alterado.

Usar force unwrap sem segurança

Usar ! em um Optional sem garantir que ele possui valor pode causar erro em tempo de execução.

Não entender Optionals

Optionals são fundamentais em Swift. Ignorar esse conceito dificulta muito o desenvolvimento na linguagem.

Confundir struct com class

Structs e classes podem parecer parecidas, mas têm diferenças importantes relacionadas a valor e referência.

Não organizar o projeto

Em projetos maiores, deixar todo o código em um único arquivo dificulta manutenção, leitura e evolução do sistema.

Exemplo simples em Swift

O exemplo abaixo mostra variáveis, função, struct, Optional e condicional. 


struct Usuario {
    let nome: String
    let idade: Int
    let email: String?
}

func apresentar(usuario: Usuario) {
    print("Nome: \(usuario.nome)")
    print("Idade: \(usuario.idade)")

    if let email = usuario.email {
        print("Email: \(email)")
    } else {
        print("Email não informado")
    }

    if usuario.idade >= 18 {
        print("Usuário maior de idade")
    } else {
        print("Usuário menor de idade")
    }
}

let usuario = Usuario(
    nome: "Gabriel",
    idade: 20,
    email: "gabriel@email.com"
)

apresentar(usuario: usuario)

Dúvidas comuns sobre Swift

Swift é difícil de aprender?

Swift é considerada uma linguagem amigável, principalmente para quem quer desenvolver aplicativos Apple. Porém, alguns conceitos como Optionals, Protocols e closures podem exigir mais prática.

Swift substituiu Objective-C?

Swift se tornou a principal linguagem moderna para desenvolvimento Apple, mas Objective-C ainda existe em sistemas antigos e projetos legados.

Swift serve apenas para iPhone?

Não. Swift é muito usada para iPhone, mas também serve para iPad, Mac, Apple Watch, Apple TV, visionOS, backend e ferramentas.

Preciso ter Mac para programar em Swift?

Para desenvolver e publicar aplicativos iOS de forma completa, normalmente é necessário usar macOS e Xcode. Porém, a linguagem Swift também pode ser estudada em outros ambientes.

Swift é boa para backend?

Swift pode ser usada no backend, mas não é tão comum nessa área quanto linguagens como Python, JavaScript, Java, Go e C#.

Vale a pena aprender Swift?

Sim, principalmente para quem deseja trabalhar com desenvolvimento mobile no ecossistema Apple ou criar aplicativos para iOS, macOS e outras plataformas da Apple.

Resumo

Swift é uma linguagem moderna, segura e performática, criada pela Apple para o desenvolvimento de aplicativos em suas plataformas. Ela possui sintaxe clara, recursos fortes de segurança e integração profunda com ferramentas como Xcode, SwiftUI e UIKit.

Seus principais conceitos incluem let, var, Optionals, structs, classes, protocols, functions, closures e tratamento de erros. Para quem deseja trabalhar com desenvolvimento mobile Apple, Swift é uma das linguagens mais importantes para aprender.
