C#

C# é uma linguagem de programação moderna criada pela Microsoft. Ela é muito usada no desenvolvimento de aplicações web, sistemas desktop, APIs, jogos, aplicações empresariais, aplicativos mobile e soluções integradas ao ecossistema .NET.

A linguagem possui sintaxe parecida com Java e C++, mas oferece recursos modernos que ajudam a criar sistemas organizados, seguros e produtivos.

O que é C#?

C# é uma linguagem de alto nível, compilada, estaticamente tipada, fortemente tipada e orientada a objetos.

Ela roda principalmente sobre a plataforma .NET, que oferece bibliotecas, ferramentas e recursos para criar diferentes tipos de aplicação. 


using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Olá, mundo!");
    }
}

Para que serve C#?

  • Criação de APIs
  • Desenvolvimento backend
  • Aplicações web com ASP.NET Core
  • Sistemas desktop com Windows Forms ou WPF
  • Jogos com Unity
  • Aplicativos mobile com .NET MAUI
  • Sistemas empresariais
  • Aplicações com banco de dados
  • Serviços em nuvem

O que é .NET?

.NET é a plataforma usada para desenvolver e executar aplicações C#. Ela fornece bibliotecas, ferramentas, compilador, ambiente de execução e suporte para vários tipos de projeto.

Com .NET, é possível criar aplicações web, desktop, mobile, jogos, APIs, microsserviços e sistemas corporativos.

C# é compilada ou interpretada?

C# é uma linguagem compilada. O código é compilado para uma linguagem intermediária executada pelo ambiente .NET.

Esse processo permite desempenho, segurança e integração com várias ferramentas da plataforma. 


dotnet run

Tipagem

C# é estaticamente tipada e fortemente tipada. Isso significa que os tipos das variáveis são verificados antes da execução e que a linguagem evita misturar tipos incompatíveis sem conversão. 


string nome = "Gabriel";
int idade = 20;
double altura = 1.75;
bool ativo = true;

Variáveis

Variáveis armazenam valores. Em C#, normalmente declaramos o tipo antes do nome da variável. 


string linguagem = "C#";
int ano = 2026;

Console.WriteLine(linguagem);
Console.WriteLine(ano);

Também é possível usar var quando o compilador consegue inferir o tipo automaticamente. 


var nome = "Gabriel";
var idade = 20;

Tipos básicos

int

Representa números inteiros.


int idade = 20;
Console.WriteLine(idade);

double

Representa números decimais com maior precisão.


double altura = 1.75;
Console.WriteLine(altura);

decimal

Representa números decimais com precisão maior, muito usado para valores financeiros.


decimal preco = 19.99m;
Console.WriteLine(preco);

char

Representa um único caractere.


char letra = 'A';
Console.WriteLine(letra);

bool

Representa verdadeiro ou falso.


bool ativo = true;
Console.WriteLine(ativo);

string

Representa textos.


string nome = "Gabriel";
Console.WriteLine(nome);

Strings

Strings armazenam textos. C# permite concatenar textos e também usar interpolação de strings. 


string nome = "Gabriel";
int idade = 20;

Console.WriteLine($"Meu nome é {nome} e tenho {idade} anos.");

Condicionais

Condicionais permitem executar blocos diferentes dependendo de uma condição. 


int idade = 18;

if (idade >= 18)
{
    Console.WriteLine("Maior de idade");
}
else
{
    Console.WriteLine("Menor de idade");
}

Switch

O switch é usado para comparar um valor com várias possibilidades. 


string linguagem = "C#";

switch (linguagem)
{
    case "C#":
        Console.WriteLine("Linguagem do ecossistema .NET");
        break;

    case "Java":
        Console.WriteLine("Linguagem da JVM");
        break;

    default:
        Console.WriteLine("Outra linguagem");
        break;
}

Laços de repetição

for


for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);
}

while


int contador = 0;

while (contador < 5)
{
    Console.WriteLine(contador);
    contador++;
}

foreach


string[] linguagens = { "C#", "Java", "Python" };

foreach (string linguagem in linguagens)
{
    Console.WriteLine(linguagem);
}

Arrays

Arrays armazenam vários valores do mesmo tipo em uma estrutura de tamanho fixo. 


string[] linguagens = { "C#", "Java", "Python" };

Console.WriteLine(linguagens[0]);

List

List é uma estrutura mais flexível que arrays, pois permite adicionar e remover elementos com facilidade. 


using System.Collections.Generic;

List<string> linguagens = new List<string>();

linguagens.Add("C#");
linguagens.Add("Java");

Console.WriteLine(linguagens[0]);

Métodos

Em C#, funções dentro de classes são chamadas de métodos. 


static int Somar(int a, int b)
{
    return a + b;
}

Classes e objetos

C# é fortemente baseada em programação orientada a objetos. Classes são modelos usados para criar objetos. 


class Usuario
{
    public string Nome;
    public int Idade;
}

Usuario usuario = new Usuario();

usuario.Nome = "Gabriel";
usuario.Idade = 20;

Construtores

Construtores são métodos especiais usados para inicializar objetos. 


class Usuario
{
    public string Nome;
    public int Idade;

    public Usuario(string nome, int idade)
    {
        Nome = nome;
        Idade = idade;
    }
}

Properties

Properties são usadas para acessar e alterar valores de uma classe de forma controlada. 


class Usuario
{
    public string Nome { get; set; }
    public int Idade { get; set; }
}

Encapsulamento

Encapsulamento protege os dados internos de uma classe e controla como eles são acessados. 


class Conta
{
    private decimal saldo;

    public void Depositar(decimal valor)
    {
        saldo += valor;
    }

    public decimal GetSaldo()
    {
        return saldo;
    }
}

Herança

Herança permite que uma classe reutilize atributos e métodos de outra classe. 


class Pessoa
{
    public string Nome { get; set; }
}

class Aluno : Pessoa
{
    public string Turma { get; set; }
}

Polimorfismo

Polimorfismo permite que métodos tenham comportamentos diferentes dependendo da classe que os implementa. 


class Animal
{
    public virtual void EmitirSom()
    {
        Console.WriteLine("Som genérico");
    }
}

class Cachorro : Animal
{
    public override void EmitirSom()
    {
        Console.WriteLine("Latido");
    }
}

Interfaces

Interfaces definem contratos que classes devem seguir. 


interface IAutenticavel
{
    void Login();
}

class Usuario : IAutenticavel
{
    public void Login()
    {
        Console.WriteLine("Usuário logado");
    }
}

Tratamento de exceções

C# usa exceções para lidar com erros durante a execução. 


try
{
    int resultado = 10 / 0;
}
catch (DivideByZeroException)
{
    Console.WriteLine("Erro: divisão por zero");
}

LINQ

LINQ é um recurso do C# usado para consultar e manipular coleções de dados de forma elegante. 


List<int> numeros = new List<int> { 1, 2, 3, 4, 5 };

var pares = numeros.Where(n => n % 2 == 0);

foreach (var numero in pares)
{
    Console.WriteLine(numero);
}

Programação assíncrona

C# possui suporte a programação assíncrona com async e await. Isso é útil para operações demoradas, como acesso a APIs e banco de dados. 


async Task BuscarDados()
{
    await Task.Delay(1000);
    Console.WriteLine("Dados carregados");
}

C# no backend com ASP.NET Core

ASP.NET Core é um framework usado para criar APIs, aplicações web e serviços backend com C#. 


app.MapGet("/", () => "API funcionando");

Ele é muito usado em sistemas empresariais, APIs REST, microsserviços e aplicações modernas com .NET.

C# em jogos com Unity

C# é a principal linguagem usada na engine Unity, uma das ferramentas mais populares para desenvolvimento de jogos 2D, 3D, mobile, desktop e realidade virtual.

Com C# na Unity, é possível controlar personagens, física, câmeras, colisões, animações, interfaces e regras do jogo.

Boas práticas em C#

  • Usar nomes claros para classes, métodos e variáveis
  • Manter classes com responsabilidades bem definidas
  • Usar properties em vez de campos públicos quando fizer sentido
  • Tratar exceções corretamente
  • Evitar métodos muito grandes
  • Organizar o projeto em camadas
  • Usar async e await corretamente
  • Evitar repetição de código

Erros comuns de iniciantes

Confundir classe com objeto

Classe é o modelo. Objeto é a instância criada a partir desse modelo.

Não entender static

Membros static pertencem à classe, e não a um objeto específico.

Esquecer ponto e vírgula

Em C#, muitas instruções precisam terminar com ponto e vírgula.

Não tratar exceções

Ignorar erros pode causar falhas inesperadas na aplicação.

Exemplo simples em C#


using System;

class Usuario
{
    public string Nome { get; set; }
    public int Idade { get; set; }

    public Usuario(string nome, int idade)
    {
        Nome = nome;
        Idade = idade;
    }

    public string VerificarIdade()
    {
        if (Idade >= 18)
        {
            return "Maior de idade";
        }

        return "Menor de idade";
    }

    public void Apresentar()
    {
        Console.WriteLine($"Nome: {Nome}");
        Console.WriteLine($"Idade: {Idade}");
        Console.WriteLine(VerificarIdade());
    }
}

class Program
{
    static void Main()
    {
        Usuario usuario = new Usuario("Gabriel", 20);

        usuario.Apresentar();
    }
}

Dúvidas comuns sobre C#

C# é bom para iniciantes?

Sim, mas exige prática com orientação a objetos, tipos, classes e métodos.

C# é usado no backend?

Sim. C# é muito usado no backend com ASP.NET Core.

C# serve para jogos?

Sim. C# é muito usado no desenvolvimento de jogos com Unity.

C# é igual a C++?

Não. Apesar do nome parecido, C# e C++ são linguagens diferentes, com objetivos, sintaxe e ecossistemas diferentes.

Vale a pena aprender C#?

Sim, principalmente para quem deseja trabalhar com backend, sistemas empresariais, aplicações .NET ou desenvolvimento de jogos com Unity.

Resumo

C# é uma linguagem moderna, robusta e muito usada no ecossistema .NET. Ela é forte em backend, sistemas corporativos, aplicações desktop, jogos com Unity e serviços em nuvem.

Seus principais conceitos incluem variáveis, tipos, condicionais, loops, arrays, listas, métodos, classes, objetos, construtores, properties, encapsulamento, herança, polimorfismo, interfaces, exceções, LINQ e programação assíncrona.
