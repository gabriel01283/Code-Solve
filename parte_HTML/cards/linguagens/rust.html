Rust

Rust é uma linguagem de programação moderna focada em segurança, desempenho e controle de memória. Ela é muito usada em sistemas que precisam ser rápidos, confiáveis e eficientes, como aplicações de baixo nível, ferramentas de linha de comando, servidores, sistemas embarcados e partes críticas de softwares.

O grande diferencial de Rust é permitir alto desempenho sem depender de um coletor de lixo tradicional. Ao mesmo tempo, a linguagem ajuda o desenvolvedor a evitar erros comuns de memória, como acessar dados inválidos, usar ponteiros incorretos ou modificar valores de forma insegura.

Rust é conhecida por sua curva de aprendizado mais difícil no começo, mas também por oferecer muita segurança e previsibilidade quando o programador entende seus principais conceitos.

O que é Rust?

Rust é uma linguagem de programação compilada, multiparadigma e fortemente tipada. Ela foi criada para resolver problemas comuns em linguagens de sistemas, principalmente relacionados à segurança de memória e concorrência.

Em linguagens como C e C++, o programador tem muito controle sobre a memória, mas também pode cometer erros perigosos. Rust tenta oferecer um nível parecido de desempenho e controle, porém com regras mais rígidas que ajudam a impedir muitos desses erros ainda durante a compilação.

Isso significa que muitos problemas são detectados antes mesmo do programa rodar. Por isso, Rust é bastante valorizada em projetos onde estabilidade e segurança são importantes.

Para que serve Rust?

Rust serve para criar programas rápidos, seguros e eficientes. Ela é muito usada quando o sistema precisa ter alto desempenho, controle de recursos e baixo risco de falhas relacionadas à memória.

  • Desenvolvimento de sistemas
  • Ferramentas de linha de comando
  • Servidores de alto desempenho
  • Sistemas embarcados
  • Aplicações WebAssembly
  • Engines de jogos
  • Blockchain e criptografia
  • Aplicações que precisam de segurança de memória

Nível da linguagem

Rust é considerada uma linguagem de nível intermediário para baixo nível. Isso significa que ela permite trabalhar próximo do hardware e da memória, mas ainda oferece recursos modernos de alto nível para organizar melhor o código.

Ela pode ser usada em áreas parecidas com C e C++, mas com uma abordagem mais segura. Ao mesmo tempo, possui recursos modernos como inferência de tipos, pattern matching, módulos, traits e gerenciamento inteligente de erros.

Rust é difícil?

Rust pode ser difícil no começo, principalmente por causa do sistema de posse de dados, conhecido como ownership. Esse conceito é uma das partes mais importantes da linguagem e também uma das que mais confundem iniciantes.

Porém, essa dificuldade tem um motivo: Rust força o programador a escrever código mais seguro. Em vez de permitir qualquer acesso à memória, a linguagem exige regras claras sobre quem é dono de um valor, quem pode apenas ler esse valor e quem pode modificá-lo.

Depois que esses conceitos são compreendidos, Rust se torna uma linguagem muito poderosa e confiável.

Rust é compilada ou interpretada?

Rust é uma linguagem compilada. Isso significa que o código escrito pelo programador é transformado em código de máquina antes de ser executado.

Esse processo permite que programas em Rust tenham alto desempenho. Como o compilador analisa o código antes da execução, ele também consegue detectar vários erros antecipadamente. 


fn main() {
    println!("Olá, mundo!");
}

O programa acima é compilado antes de ser executado. A função main é o ponto inicial de execução de um programa Rust.

Tipagem

Rust é uma linguagem estaticamente tipada e fortemente tipada.

Ser estaticamente tipada significa que os tipos das variáveis são verificados em tempo de compilação. Ser fortemente tipada significa que a linguagem evita conversões automáticas perigosas entre tipos diferentes.

Rust também possui inferência de tipos. Isso significa que, em muitos casos, o compilador consegue descobrir o tipo da variável sem que o programador precise escrever explicitamente. 


let idade = 20;
let nome = "Gabriel";
let ativo = true;

Mesmo sem escrever os tipos, o compilador consegue entender que idade é um número inteiro, nome é um texto e ativo é um valor booleano.

Variáveis em Rust

Em Rust, variáveis são criadas usando a palavra-chave let. Por padrão, variáveis em Rust são imutáveis. Isso significa que, depois de receberem um valor, elas não podem ser alteradas. 


let nome = "Gabriel";
println!("{}", nome);

Se quisermos permitir alteração no valor da variável, usamos mut. 


let mut idade = 20;
idade = 21;

println!("{}", idade);

Essa escolha ajuda a evitar mudanças acidentais no código. O programador precisa deixar claro quando uma variável pode ser modificada.

Tipos primitivos

Inteiros

Representam números inteiros. Rust possui diferentes tamanhos de inteiros, como i32, i64, u32 e u64. 


let idade: i32 = 20;
println!("{}", idade);

Ponto flutuante

Representam números com casas decimais. Os tipos mais comuns são f32 e f64. 


let altura: f64 = 1.75;
println!("{}", altura);

Booleano

Representa valores verdadeiro ou falso. 


let ativo: bool = true;
println!("{}", ativo);

Caractere

Representa um único caractere Unicode. 


let letra: char = 'A';
println!("{}", letra);

Texto

Rust possui diferentes formas de lidar com texto, como &str e String. 


let nome: &str = "Gabriel";
let linguagem: String = String::from("Rust");

println!("{}", nome);
println!("{}", linguagem);

Diferença entre &str e String

Uma dúvida muito comum em Rust é a diferença entre &str e String.

&str é uma referência para uma sequência de texto. Normalmente é usado quando o texto é fixo ou quando estamos apenas acessando uma fatia de texto. 


let texto: &str = "Olá";

String é um tipo de texto que pode crescer e ser modificado. Ele armazena dados na memória dinâmica. 


let mut nome = String::from("Gabriel");
nome.push_str(" Saraiva");

println!("{}", nome);

Ownership

Ownership, ou posse, é um dos conceitos mais importantes de Rust. Ele define qual variável é responsável por um valor na memória.

Em Rust, cada valor tem um dono. Quando o dono sai de escopo, o valor é removido da memória automaticamente. Isso permite que Rust gerencie memória sem precisar de um coletor de lixo tradicional. 


fn main() {
    let nome = String::from("Gabriel");
    println!("{}", nome);
}

Nesse exemplo, a variável nome é dona da String. Quando a função termina, Rust libera a memória usada por esse valor.

Move

Em Rust, quando um valor é atribuído a outra variável, a posse pode ser movida. Depois disso, a variável original deixa de ser válida. 


let nome1 = String::from("Gabriel");
let nome2 = nome1;

println!("{}", nome2);

Nesse caso, a posse da String foi movida de nome1 para nome2. Por isso, usar nome1 depois disso causaria erro de compilação.

Esse comportamento evita que duas variáveis tentem liberar ou modificar o mesmo valor de forma insegura.

Borrowing

Borrowing significa empréstimo. Em vez de transferir a posse de um valor, podemos emprestar uma referência para uma função ou variável. 


fn mostrar_nome(nome: &String) {
    println!("{}", nome);
}

fn main() {
    let nome = String::from("Gabriel");

    mostrar_nome(&nome);

    println!("{}", nome);
}

Nesse exemplo, a função apenas pega uma referência para o valor. A posse continua com a variável original.

Referências mutáveis

Se quisermos permitir que uma função modifique um valor emprestado, usamos uma referência mutável. 


fn alterar_nome(nome: &mut String) {
    nome.push_str(" Saraiva");
}

fn main() {
    let mut nome = String::from("Gabriel");

    alterar_nome(&mut nome);

    println!("{}", nome);
}

Rust impõe regras rígidas para referências mutáveis. Em um mesmo momento, você pode ter várias referências imutáveis ou apenas uma referência mutável.

Funções

Funções em Rust são declaradas usando a palavra-chave fn. Elas podem receber parâmetros e retornar valores. 


fn somar(a: i32, b: i32) -> i32 {
    a + b
}

fn main() {
    let resultado = somar(5, 3);

    println!("{}", resultado);
}

Em Rust, a última expressão de uma função pode ser retornada sem usar a palavra-chave return, desde que não tenha ponto e vírgula.

Condicionais

Rust usa if, else if e else para tomar decisões. 


let idade = 18;

if idade >= 18 {
    println!("Maior de idade");
} else {
    println!("Menor de idade");
}

Em Rust, condições precisam resultar em valores booleanos. A linguagem não aceita usar números diretamente como condição.

Laços de repetição

Rust possui diferentes formas de repetição, como loop, while e for.

loop


let mut contador = 0;

loop {
    contador += 1;

    if contador == 3 {
        break;
    }
}

while


let mut numero = 0;

while numero < 5 {
    println!("{}", numero);
    numero += 1;
}

for


for numero in 1..5 {
    println!("{}", numero);
}

Match

match é uma estrutura poderosa usada para comparar valores com diferentes padrões. Ele é parecido com switch em outras linguagens, mas muito mais expressivo. 


let numero = 2;

match numero {
    1 => println!("Um"),
    2 => println!("Dois"),
    3 => println!("Três"),
    _ => println!("Outro número"),
}

O símbolo _ representa qualquer outro caso que não foi tratado.

Structs

Structs são usadas para criar tipos personalizados agrupando diferentes campos. Elas são parecidas com registros ou classes simples em outras linguagens. 


struct Usuario {
    nome: String,
    idade: i32,
}

fn main() {
    let usuario = Usuario {
        nome: String::from("Gabriel"),
        idade: 20,
    };

    println!("{}", usuario.nome);
}

Structs ajudam a organizar dados relacionados dentro de um mesmo tipo.

Enums

Enums permitem definir um tipo que pode assumir diferentes variantes. Eles são muito usados em Rust para representar estados, opções e resultados. 


enum Status {
    Ativo,
    Inativo,
    Bloqueado,
}

fn main() {
    let status = Status::Ativo;
}

Option

Rust não usa null da mesma forma que muitas linguagens. Em vez disso, usa o tipo Option para representar um valor que pode existir ou não. 


let nome: Option<String> = Some(String::from("Gabriel"));
let vazio: Option<String> = None;

Isso evita muitos erros comuns causados por tentar acessar valores nulos.

Result

Rust usa o tipo Result para lidar com operações que podem dar certo ou falhar. 


fn dividir(a: i32, b: i32) -> Result<i32, String> {
    if b == 0 {
        Err(String::from("Não é possível dividir por zero"))
    } else {
        Ok(a / b)
    }
}

Isso torna o tratamento de erros mais explícito e seguro.

Cargo

Cargo é o gerenciador de pacotes e ferramenta de build oficial do Rust. Ele ajuda a criar projetos, compilar código, executar testes e instalar dependências.

Para criar um novo projeto Rust, usamos: 


cargo new meu_projeto

Para executar o projeto: 


cargo run

Para compilar o projeto: 


cargo build

Crates

Crates são pacotes em Rust. Eles podem conter bibliotecas ou aplicações. Quando um projeto precisa de uma funcionalidade externa, é comum adicionar uma crate como dependência.

As dependências ficam declaradas no arquivo Cargo.toml. 


[dependencies]
serde = "1.0"

Rust e C++

Rust é frequentemente comparada com C++ porque ambas podem ser usadas em desenvolvimento de sistemas e aplicações de alto desempenho.

A diferença principal é que Rust tenta evitar erros de memória por meio de regras verificadas pelo compilador. C++ oferece muito controle, mas também permite mais situações perigosas se o programador não tomar cuidado.

  • Rust prioriza segurança de memória
  • C++ possui ecossistema mais antigo e amplo
  • Rust tem regras rígidas de ownership
  • C++ permite maior liberdade, mas exige mais cuidado manual

Onde Rust é usado?

Rust é usado em projetos que precisam de desempenho, segurança e confiabilidade. Ele aparece em ferramentas de desenvolvimento, servidores, sistemas embarcados, projetos de infraestrutura e aplicações que exigem controle de memória.

  • Ferramentas de terminal
  • Serviços de backend
  • Sistemas operacionais
  • WebAssembly
  • Blockchain
  • Criptografia
  • Aplicações de rede
  • Softwares de alta performance

Boas práticas em Rust

Para escrever Rust de forma organizada, é importante seguir boas práticas desde o começo.

  • Usar nomes claros para variáveis e funções
  • Evitar mutabilidade desnecessária
  • Tratar erros com Result em vez de ignorá-los
  • Usar Option quando um valor puder não existir
  • Organizar o projeto com módulos
  • Entender ownership antes de escrever códigos muito complexos
  • Usar cargo fmt para formatar o código
  • Usar cargo clippy para receber sugestões de melhoria

Erros comuns de iniciantes

Tentar modificar variável imutável

Em Rust, variáveis são imutáveis por padrão. Para modificar uma variável, é necessário usar mut. 


let mut idade = 20;
idade = 21;

Confundir ownership com cópia

Alguns valores são movidos em vez de copiados. Isso pode causar erro quando o programador tenta usar a variável original depois do move.

Não tratar Result

Operações que podem falhar retornam Result. Ignorar esse tratamento pode gerar problemas na lógica do programa.

Usar referência mutável de forma incorreta

Rust limita o uso de referências mutáveis para evitar conflitos e condições de corrida.

Exemplo simples em Rust

O exemplo abaixo mostra variáveis, função, condicional e impressão no terminal. 


fn verificar_idade(idade: i32) -> String {
    if idade >= 18 {
        String::from("Maior de idade")
    } else {
        String::from("Menor de idade")
    }
}

fn main() {
    let nome = String::from("Gabriel");
    let idade = 20;

    let resultado = verificar_idade(idade);

    println!("Nome: {}", nome);
    println!("Idade: {}", idade);
    println!("Resultado: {}", resultado);
}

Dúvidas comuns sobre Rust

Rust é boa para iniciantes?

Rust pode ser mais difícil para iniciantes absolutos, porque exige entender conceitos como ownership, borrowing e tipos. Porém, ela ensina boas práticas importantes desde o começo.

Rust substitui C++?

Em alguns projetos, Rust pode ser uma alternativa a C++. Porém, C++ ainda é muito usado e possui um ecossistema enorme. Rust é mais uma opção moderna para sistemas seguros e performáticos.

Rust serve para backend?

Sim. Rust pode ser usada no backend com frameworks e bibliotecas voltadas para criação de APIs, servidores e aplicações de rede.

Rust tem garbage collector?

Não no modelo tradicional. Rust gerencia memória por meio de ownership, borrowing e regras verificadas em tempo de compilação.

Vale a pena aprender Rust?

Sim, principalmente para quem se interessa por desempenho, sistemas, segurança, backend de alta performance, WebAssembly ou programação de baixo nível.

Resumo

Rust é uma linguagem moderna, segura e performática, muito usada em sistemas que precisam de confiabilidade e controle de memória. Ela possui uma curva de aprendizado maior, mas recompensa o desenvolvedor com código seguro, eficiente e previsível.

Seus conceitos principais, como ownership, borrowing, Result e Option, tornam Rust diferente de muitas linguagens tradicionais. Aprender Rust ajuda o programador a entender melhor memória, segurança, compilação e desenvolvimento de software robusto.
