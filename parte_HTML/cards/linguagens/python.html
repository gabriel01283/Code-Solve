Python

Python é uma linguagem de programação muito popular, conhecida por sua sintaxe simples, clara e fácil de aprender. Ela é usada em diversas áreas da tecnologia, como desenvolvimento web, automação, análise de dados, inteligência artificial, ciência de dados, scripts, APIs e aplicações desktop.

Uma das principais vantagens do Python é permitir que o desenvolvedor escreva soluções com menos código quando comparado a linguagens mais verbosas. Por isso, Python é muito recomendado para iniciantes, mas também é usado em projetos profissionais e sistemas complexos.

Mesmo sendo uma linguagem simples de ler, Python é bastante poderosa por causa de seu ecossistema de bibliotecas, frameworks e ferramentas.

O que é Python?

Python é uma linguagem de programação de alto nível, interpretada, multiparadigma e dinamicamente tipada.

Ser de alto nível significa que Python possui uma sintaxe mais próxima da linguagem humana, facilitando a leitura e escrita do código. Ser interpretada significa que o código normalmente é executado por um interpretador, sem a necessidade de gerar manualmente um arquivo executável antes de rodar.

Python permite diferentes estilos de programação, como programação procedural, programação orientada a objetos e programação funcional.

Para que serve Python?

Python é uma linguagem muito versátil. Ela pode ser usada tanto para tarefas simples quanto para sistemas maiores.

  • Desenvolvimento web
  • Criação de APIs
  • Automação de tarefas
  • Análise de dados
  • Ciência de dados
  • Inteligência artificial
  • Machine learning
  • Scripts de sistema
  • Aplicações desktop
  • Testes automatizados

Nível da linguagem

Python é uma linguagem de alto nível. Isso significa que ela esconde muitos detalhes internos do computador, como gerenciamento manual de memória, ponteiros e instruções muito próximas do hardware.

Essa característica torna Python mais fácil de aprender e usar, principalmente para quem está começando na programação.

Porém, por ser uma linguagem de alto nível e interpretada, Python geralmente não é tão rápida quanto linguagens compiladas como C, C++, Rust ou Go em tarefas que exigem desempenho extremo.

Python é compilada ou interpretada?

Python é normalmente classificada como uma linguagem interpretada. Isso significa que o código é executado por um interpretador, que lê e executa as instruções.

Na prática, Python também passa por etapas internas de compilação para bytecode, mas para o programador iniciante o mais importante é entender que normalmente executamos Python diretamente, sem precisar compilar manualmente como em C ou C++. 


print("Olá, mundo!")

Esse exemplo exibe uma mensagem na tela usando a função print.

Tipagem

Python é uma linguagem dinamicamente tipada e fortemente tipada.

Ser dinamicamente tipada significa que não precisamos declarar o tipo da variável antes de usá-la. O próprio Python identifica o tipo do valor durante a execução. 


nome = "Gabriel"
idade = 20
altura = 1.75
ativo = True

Nesse exemplo, Python entende automaticamente que nome é um texto, idade é um número inteiro, altura é um número decimal e ativo é um valor booleano.

Ser fortemente tipada significa que Python não mistura tipos incompatíveis automaticamente de forma perigosa.

Variáveis

Variáveis são espaços usados para armazenar valores. Em Python, criamos uma variável escrevendo seu nome, o sinal de igual e o valor que será armazenado. 


nome = "Gabriel"
idade = 20

print(nome)
print(idade)

Python não exige o uso de palavras como let, var ou a declaração explícita do tipo da variável.

Tipos primitivos

int

Representa números inteiros, ou seja, números sem casas decimais. 


idade = 20
print(idade)

float

Representa números com casas decimais. 


altura = 1.75
print(altura)

str

Representa textos, ou seja, sequências de caracteres. 


nome = "Gabriel"
print(nome)

bool

Representa valores lógicos: verdadeiro ou falso. 


ativo = True
print(ativo)

None

Representa ausência de valor. 


resultado = None
print(resultado)

Strings

Strings são usadas para armazenar textos. Em Python, podemos criar strings usando aspas simples ou aspas duplas. 


nome = "Gabriel"
linguagem = 'Python'

print(nome)
print(linguagem)

Também é possível montar textos usando f-strings, que permitem inserir variáveis dentro de uma string. 


nome = "Gabriel"
idade = 20

print(f"Meu nome é {nome} e tenho {idade} anos.")

Listas

Listas são estruturas usadas para armazenar vários valores em uma única variável. Elas podem guardar números, textos, objetos e outros tipos de dados. 


linguagens = ["Python", "Java", "JavaScript"]

print(linguagens[0])

Em Python, a primeira posição de uma lista é o índice zero. 


linguagens.append("C++")

print(linguagens)

O método append adiciona um novo item ao final da lista.

Tuplas

Tuplas são parecidas com listas, mas normalmente são imutáveis. Isso significa que seus valores não devem ser alterados depois de definidos. 


coordenada = (10, 20)

print(coordenada[0])
print(coordenada[1])

Tuplas são úteis para representar conjuntos fixos de informações.

Dicionários

Dicionários armazenam dados no formato chave e valor. Eles são muito usados para representar objetos, configurações e respostas de APIs. 


usuario = {
    "nome": "Gabriel",
    "idade": 20,
    "email": "gabriel@email.com"
}

print(usuario["nome"])

Nesse exemplo, a chave nome está associada ao valor Gabriel.

Condicionais

Condicionais permitem executar partes diferentes do código dependendo de uma condição. Em Python, usamos if, elif e else. 


idade = 18

if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")

Diferente de muitas linguagens, Python usa indentação para definir os blocos de código.

Laços de repetição

Laços de repetição permitem executar um bloco de código várias vezes.

for


linguagens = ["Python", "Java", "C++"]

for linguagem in linguagens:
    print(linguagem)

while


contador = 0

while contador < 5:
    print(contador)
    contador += 1

Funções

Funções são blocos de código reutilizáveis. Elas ajudam a organizar o programa e evitar repetição. 


def somar(a, b):
    return a + b

resultado = somar(5, 3)

print(resultado)

Em Python, usamos a palavra-chave def para criar funções.

Parâmetros e retorno

Funções podem receber parâmetros e devolver resultados usando return. 


def apresentar(nome, idade):
    return f"{nome} tem {idade} anos."

mensagem = apresentar("Gabriel", 20)

print(mensagem)

Os parâmetros funcionam como valores de entrada para a função.

Classes e objetos

Python suporta programação orientada a objetos. Classes são modelos usados para criar objetos. 


class Usuario:
    def __init__(self, nome, idade):
        self.nome = nome
        self.idade = idade

usuario = Usuario("Gabriel", 20)

print(usuario.nome)
print(usuario.idade)

O método __init__ é o construtor da classe. Ele é executado quando um novo objeto é criado.

O que é self?

Em Python, self representa o próprio objeto que está usando o método. Ele permite acessar atributos e comportamentos do objeto. 


class Pessoa:
    def __init__(self, nome):
        self.nome = nome

    def apresentar(self):
        print(f"Meu nome é {self.nome}")

pessoa = Pessoa("Gabriel")
pessoa.apresentar()

Módulos

Módulos são arquivos Python que podem conter funções, classes e variáveis. Eles ajudam a organizar o código em partes menores. 


import math

print(math.sqrt(25))

Nesse exemplo, o módulo math foi importado para usar funções matemáticas.

Python possui muitas bibliotecas e frameworks que facilitam o desenvolvimento de diferentes tipos de projeto.

  • FastAPI: criação de APIs modernas
  • Django: desenvolvimento web completo
  • Flask: criação de aplicações web simples e APIs
  • Pandas: análise de dados
  • NumPy: computação numérica
  • Matplotlib: criação de gráficos
  • TensorFlow: inteligência artificial e machine learning
  • Pytest: testes automatizados

Ambiente virtual

Ambientes virtuais servem para isolar as dependências de um projeto Python. Isso evita conflitos entre bibliotecas usadas em projetos diferentes. 


python -m venv venv

Depois de criar o ambiente virtual, ele pode ser ativado e usado para instalar bibliotecas específicas daquele projeto.

pip

pip é o gerenciador de pacotes mais usado em Python. Ele permite instalar bibliotecas externas. 


pip install fastapi
pip install uvicorn

Em projetos Python, é comum salvar as dependências no arquivo requirements.txt. 


pip freeze > requirements.txt

Python no backend

Python é muito usado no desenvolvimento backend. Com frameworks como FastAPI, Django e Flask, é possível criar APIs, sistemas web, autenticação, integração com banco de dados e regras de negócio.

No backend, Python costuma receber requisições do front-end, processar dados, acessar o banco e devolver respostas para a aplicação. 


from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"mensagem": "API funcionando"}

Python e banco de dados

Python pode se conectar a bancos de dados relacionais e não relacionais. Em aplicações web, é comum usar Python junto com PostgreSQL, MySQL, SQLite ou MongoDB.

Essa conexão permite cadastrar usuários, salvar comentários, consultar dados, atualizar informações e remover registros.

Boas práticas em Python

Escrever Python de forma organizada ajuda a manter o código legível, simples e fácil de modificar.

  • Usar nomes claros para variáveis e funções
  • Manter a indentação correta
  • Separar o código em arquivos e módulos
  • Evitar funções muito grandes
  • Usar ambiente virtual nos projetos
  • Salvar dependências em requirements.txt
  • Tratar erros com try e except quando necessário
  • Evitar repetição de código
  • Escrever comentários apenas quando ajudarem a entender a lógica

Erros comuns de iniciantes

Errar a indentação

Python usa indentação para definir blocos de código. Um espaço errado pode causar erro ou mudar o funcionamento do programa.

Confundir = com ==

O sinal = atribui valor. O sinal == compara valores.

Esquecer os dois pontos

Estruturas como if, for, while, def e class usam dois pontos no final da linha. 


if idade >= 18:
    print("Maior de idade")

Confundir lista com dicionário

Listas usam índices numéricos. Dicionários usam chaves para acessar valores.

Não usar ambiente virtual

Instalar bibliotecas sem ambiente virtual pode gerar conflitos entre projetos.

Exemplo simples em Python

O exemplo abaixo mostra variáveis, função, lista, dicionário, condicional e laço. 


def verificar_idade(idade):
    if idade >= 18:
        return "Maior de idade"
    else:
        return "Menor de idade"

usuario = {
    "nome": "Gabriel",
    "idade": 20,
    "linguagens": ["Python", "JavaScript", "Java"]
}

print(f"Nome: {usuario['nome']}")
print(f"Idade: {usuario['idade']}")
print(verificar_idade(usuario["idade"]))

print("Linguagens:")

for linguagem in usuario["linguagens"]:
    print(linguagem)

Dúvidas comuns sobre Python

Python é bom para iniciantes?

Sim. Python é uma das linguagens mais recomendadas para quem está começando, porque possui uma sintaxe simples e fácil de entender.

Python serve para backend?

Sim. Python é muito usado no backend com frameworks como FastAPI, Django e Flask.

Python é usado em inteligência artificial?

Sim. Python é uma das linguagens mais usadas em inteligência artificial, machine learning e ciência de dados.

Python é rápido?

Python é rápido para desenvolver, mas não costuma ser a linguagem mais rápida em desempenho bruto. Para muitas aplicações, isso não é um problema.

Python substitui JavaScript no front-end?

Não. Python é muito usado no backend e em outras áreas, mas JavaScript continua sendo a principal linguagem executada diretamente no navegador.

Vale a pena aprender Python?

Sim. Python é útil para iniciantes e também para áreas profissionais como backend, automação, dados, inteligência artificial e testes.

Resumo

Python é uma linguagem simples, versátil e poderosa. Ela é muito usada por iniciantes e profissionais em diversas áreas, como backend, automação, dados, inteligência artificial e criação de APIs.

Seus principais conceitos incluem variáveis, tipos, listas, dicionários, condicionais, laços, funções, classes, módulos e bibliotecas. Por sua sintaxe clara e grande ecossistema, Python é uma das linguagens mais importantes para quem deseja entrar no mundo da programação.
