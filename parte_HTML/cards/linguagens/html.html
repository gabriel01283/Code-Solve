HTML

HTML é a linguagem de marcação usada para estruturar páginas da web. Ela define os elementos que aparecem em um site, como títulos, parágrafos, imagens, links, listas, tabelas, formulários e áreas de conteúdo.

Quando acessamos uma página na internet, o navegador lê o código HTML e interpreta sua estrutura para exibir o conteúdo de forma organizada para o usuário.

HTML é uma das bases do desenvolvimento web. Junto com CSS e JavaScript, forma o conjunto principal de tecnologias usadas para criar páginas e aplicações web modernas.

O que é HTML?

HTML significa HyperText Markup Language, ou seja, Linguagem de Marcação de Hipertexto.

O HTML não é usado para criar lógica complexa como uma linguagem de programação. Ele serve para marcar e organizar o conteúdo da página. Por isso, dizemos que HTML é uma linguagem de marcação.

Com HTML, podemos informar ao navegador que um texto é um título, que outro texto é um parágrafo, que determinado trecho é um link, que uma imagem deve aparecer na tela ou que existe um formulário para o usuário preencher.

HTML é uma linguagem de programação?

Tecnicamente, HTML não é considerado uma linguagem de programação, porque ele não possui estruturas como variáveis, funções, condições, laços de repetição ou lógica de processamento.

HTML é uma linguagem de marcação. Sua função principal é estruturar o conteúdo da página.

Mesmo assim, HTML é essencial para qualquer pessoa que deseja aprender desenvolvimento web. Sem HTML, não existe estrutura visual para uma página ser exibida no navegador.

Para que serve HTML?

HTML serve para criar a estrutura principal de uma página web. Ele organiza o conteúdo e define quais elementos existirão na página.

  • Criar títulos e subtítulos
  • Adicionar parágrafos de texto
  • Inserir imagens
  • Criar links entre páginas
  • Montar listas ordenadas e não ordenadas
  • Criar tabelas
  • Construir formulários
  • Separar áreas da página, como cabeçalho, menu, conteúdo e rodapé

Estrutura básica de um documento HTML

Todo arquivo HTML possui uma estrutura básica. Essa estrutura informa ao navegador o tipo do documento, o idioma da página, as configurações principais e o conteúdo que será exibido. 


<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Minha Página</title>
</head>
<body>

    <h1>Olá, mundo!</h1>
    <p>Minha primeira página HTML.</p>

</body>
</html>

Cada parte dessa estrutura tem uma função importante dentro do documento.

Principais partes de um arquivo HTML

<!DOCTYPE html>

Informa ao navegador que o documento está usando HTML5, que é a versão moderna do HTML.

<html>

É o elemento raiz da página. Todo o conteúdo HTML fica dentro dele.

<head>

Contém informações sobre a página, como título, codificação de caracteres, configurações de responsividade, links para arquivos CSS e scripts.

<body>

Contém tudo que aparece visualmente para o usuário, como textos, imagens, botões, links, listas e formulários.

O que são tags?

Tags são marcações usadas para criar elementos HTML. Normalmente, uma tag possui uma abertura e um fechamento. 


<p>Este é um parágrafo.</p>

Nesse exemplo, <p> abre o parágrafo e </p> fecha o parágrafo.

Algumas tags não precisam de fechamento, como a tag usada para inserir imagens. 


<img src="imagem.png" alt="Descrição da imagem">

Tags e elementos são a mesma coisa?

Não exatamente. A tag é a marcação em si. O elemento é o conjunto completo formado pela tag de abertura, conteúdo e tag de fechamento. 


<h1>Título da página</h1>

Nesse caso, <h1> e </h1> são tags. O conjunto inteiro é o elemento HTML.

O que são atributos?

Atributos são informações extras colocadas dentro das tags. Eles modificam ou complementam o comportamento de um elemento. 


<a href="https://exemplo.com">Acessar site</a>

Nesse exemplo, href é um atributo da tag <a>. Ele informa para qual endereço o link deve levar.

Outro exemplo comum é o atributo class, usado para aplicar estilos com CSS. 


<p class="texto-destaque">Texto importante</p>

Títulos em HTML

HTML possui seis níveis de títulos, indo de <h1> até <h6>. O <h1> representa o título mais importante da página, enquanto o <h6> representa o menos importante. 


<h1>Título principal</h1>
<h2>Subtítulo</h2>
<h3>Tópico interno</h3>

É uma boa prática usar apenas um <h1> principal por página e organizar os outros títulos de forma hierárquica.

Parágrafos

A tag <p> é usada para criar parágrafos de texto. Ela é uma das tags mais comuns em páginas HTML. 


<p>
    HTML é usado para estruturar o conteúdo de páginas web.
</p>

Links

Links permitem navegar entre páginas ou acessar sites externos. Em HTML, links são criados com a tag <a>. 


<a href="https://www.google.com">Acessar Google</a>

O atributo href define o destino do link.

Links também podem apontar para páginas internas do próprio projeto. 


<a href="./sobre.html">Sobre o site</a>

Imagens

Imagens são inseridas com a tag <img>. Essa tag usa principalmente dois atributos: src e alt. 


<img src="imagem.png" alt="Descrição da imagem">

O atributo src indica o caminho da imagem. O atributo alt descreve a imagem e é importante para acessibilidade e para mecanismos de busca.

Listas

HTML permite criar listas ordenadas e listas não ordenadas.

Lista não ordenada

É usada quando a ordem dos itens não importa. 


<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Lista ordenada

É usada quando a ordem dos itens importa. 


<ol>
    <li>Criar o HTML</li>
    <li>Adicionar o CSS</li>
    <li>Conectar o JavaScript</li>
</ol>

Tabelas

Tabelas são usadas para organizar dados em linhas e colunas. 


<table>
    <tr>
        <th>Linguagem</th>
        <th>Uso principal</th>
    </tr>

    <tr>
        <td>HTML</td>
        <td>Estrutura de páginas</td>
    </tr>
</table>

A tag <table> cria a tabela. A tag <tr> cria uma linha. A tag <th> cria uma célula de cabeçalho. A tag <td> cria uma célula comum.

Formulários

Formulários permitem que o usuário envie informações para o sistema. Eles são muito usados em páginas de login, cadastro, busca, comentários e contato. 


<form>
    <label for="nome">Nome</label>
    <input type="text" id="nome" placeholder="Digite seu nome">

    <button type="submit">Enviar</button>
</form>

Um formulário pode conter campos de texto, senha, email, número, botões, caixas de seleção, áreas de texto e outros tipos de entrada.

Tipos comuns de input

A tag <input> pode receber diferentes tipos através do atributo type.

  • text: campo de texto comum
  • email: campo para email
  • password: campo para senha
  • number: campo numérico
  • checkbox: caixa de seleção
  • radio: opção única dentro de um grupo
  • submit: botão de envio

<input type="email" placeholder="Digite seu email">
<input type="password" placeholder="Digite sua senha">

HTML semântico

HTML semântico significa usar tags que possuem significado claro sobre o conteúdo que representam.

Em vez de usar apenas várias <div>, podemos usar tags mais específicas, como:

  • <header>: cabeçalho da página ou seção
  • <nav>: área de navegação
  • <main>: conteúdo principal da página
  • <section>: seção de conteúdo
  • <article>: conteúdo independente
  • <aside>: conteúdo lateral ou complementar
  • <footer>: rodapé

O HTML semântico melhora a organização do código, a acessibilidade e a compreensão da página por mecanismos de busca.

Diferença entre div e span

div

A tag <div> é usada para criar blocos genéricos de conteúdo. Ela normalmente ocupa uma área maior da página. 


<div>
    <h2>Título</h2>
    <p>Texto dentro da div.</p>
</div>

span

A tag <span> é usada para marcar pequenos trechos dentro de uma linha de texto. 


<p>Este é um <span>texto destacado</span>.</p>

Relação entre HTML, CSS e JavaScript

HTML, CSS e JavaScript trabalham juntos na criação de páginas web. Cada um possui uma função diferente.

  • HTML: estrutura o conteúdo da página
  • CSS: define o visual, as cores, tamanhos e layouts
  • JavaScript: adiciona interatividade e lógica

Uma comparação simples seria:

  • HTML é o esqueleto da página
  • CSS é a aparência da página
  • JavaScript é o comportamento da página

Como conectar HTML com CSS

Para usar um arquivo CSS em uma página HTML, utilizamos a tag <link> dentro do <head>. 


<link rel="stylesheet" href="style.css">

O atributo href indica o caminho até o arquivo CSS.

Como conectar HTML com JavaScript

Para conectar um arquivo JavaScript ao HTML, usamos a tag <script>. 


<script src="script.js" defer></script>

O atributo src aponta para o arquivo JavaScript. O atributo defer faz o script esperar o HTML ser carregado antes de executar.

Acessibilidade em HTML

Acessibilidade significa criar páginas que possam ser usadas por diferentes pessoas, incluindo usuários com deficiência visual, motora ou cognitiva.

Algumas boas práticas de acessibilidade em HTML são:

  • Usar textos alternativos em imagens com o atributo alt
  • Usar labels em formulários
  • Organizar corretamente os títulos da página
  • Usar HTML semântico
  • Evitar criar botões usando elementos que não são botões

<label for="email">Email</label>
<input type="email" id="email">

HTML e SEO

SEO significa otimização para mecanismos de busca. Um HTML bem estruturado ajuda buscadores a entenderem melhor o conteúdo da página.

Algumas práticas importantes são:

  • Usar títulos bem organizados
  • Preencher corretamente a tag <title>
  • Usar descrições claras no conteúdo
  • Usar texto alternativo em imagens
  • Utilizar HTML semântico

Boas práticas em HTML

Escrever HTML de forma organizada facilita a manutenção do projeto e evita problemas no futuro.

  • Manter a indentação organizada
  • Usar nomes de classes claros
  • Evitar repetição desnecessária de código
  • Usar tags semânticas quando fizer sentido
  • Separar estrutura, estilo e comportamento
  • Não colocar CSS grande diretamente dentro do HTML
  • Não colocar JavaScript grande diretamente dentro do HTML
  • Usar caminhos corretos para arquivos CSS, JS e imagens

Erros comuns de iniciantes

Esquecer de fechar tags

Algumas tags precisam ser fechadas corretamente. Esquecer o fechamento pode quebrar a estrutura da página.

Usar caminhos errados

Um erro muito comum é errar o caminho de arquivos CSS, JavaScript ou imagens. Quando isso acontece, o navegador não consegue carregar o arquivo.

Usar muitas divs sem necessidade

A tag <div> é útil, mas usar apenas divs pode deixar o HTML pouco semântico e mais difícil de entender.

Confundir HTML com CSS

HTML não é responsável pelo design da página. A função do HTML é estruturar o conteúdo. O visual deve ficar principalmente no CSS.

Exemplo simples de página HTML

O exemplo abaixo mostra uma página simples com navegação, título, texto, imagem e botão. 


<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Exemplo HTML</title>
</head>
<body>

    <nav>
        <h1>Meu Site</h1>
        <a href="./index.html">Home</a>
    </nav>

    <main>
        <section>
            <h2>Bem-vindo</h2>
            <p>Esta é uma página criada com HTML.</p>
            <button>Clique aqui</button>
        </section>
    </main>

</body>
</html>

Onde HTML é usado?

HTML é usado em praticamente toda a web. Mesmo aplicações modernas feitas com frameworks como React, Angular, Vue ou Next.js acabam gerando HTML para ser interpretado pelo navegador.

  • Páginas institucionais
  • Blogs
  • Sistemas web
  • Landing pages
  • Portfólios
  • Lojas virtuais
  • Aplicações com front-end moderno

Dúvidas comuns sobre HTML

HTML é difícil de aprender?

Não. HTML é uma das tecnologias mais acessíveis para quem está começando no desenvolvimento web. A dificuldade aumenta conforme o projeto fica maior e exige mais organização.

Preciso aprender HTML antes de CSS?

Sim, é recomendado. O CSS estiliza elementos HTML, então entender a estrutura da página ajuda muito antes de estudar estilos.

Preciso aprender HTML antes de JavaScript?

Sim. JavaScript normalmente manipula elementos HTML, então é importante entender como os elementos são criados antes de adicionar interatividade.

HTML ainda é usado em 2026?

Sim. HTML continua sendo essencial para a web. Mesmo com frameworks modernos, o navegador ainda interpreta HTML para exibir páginas.

HTML sozinho cria um site completo?

HTML sozinho cria a estrutura, mas normalmente um site completo também usa CSS para aparência e JavaScript para interatividade.

Resumo

HTML é a base estrutural da web. Ele organiza o conteúdo de uma página e permite que navegadores exibam textos, imagens, links, listas, formulários e outros elementos.

Embora não seja uma linguagem de programação, HTML é indispensável para qualquer pessoa que queira trabalhar com desenvolvimento web. Dominar HTML facilita o aprendizado de CSS, JavaScript, frameworks front-end e criação de sistemas web.
