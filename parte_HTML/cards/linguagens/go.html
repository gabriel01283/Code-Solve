Go

Go, também conhecida como Golang, é uma linguagem de programação criada pelo Google. Ela foi desenvolvida para ser simples, rápida, eficiente e adequada para sistemas modernos, principalmente servidores, APIs, ferramentas de linha de comando, microsserviços e aplicações de rede.

Go se destaca por sua sintaxe limpa, compilação rápida e facilidade para trabalhar com concorrência. Por isso, é muito usada em aplicações que precisam lidar com muitas requisições ao mesmo tempo.

O que é Go?

Go é uma linguagem compilada, estaticamente tipada e de alto desempenho. Ela foi criada com foco em simplicidade e produtividade.

Diferente de linguagens muito complexas, Go tenta manter poucos recursos, mas bem definidos. Isso ajuda equipes a escreverem código mais padronizado e fácil de manter. 


package main

import "fmt"

func main() {
    fmt.Println("Olá, mundo!")
}

Nível da linguagem

Go é considerada uma linguagem de alto nível, mas com foco em desempenho. Ela não exige que o programador lide diretamente com detalhes complexos de memória, como em C ou C++, mas ainda assim entrega boa velocidade.

Go possui garbage collector, ou seja, a linguagem gerencia automaticamente parte da memória usada pelo programa.

Go é compilada ou interpretada?

Go é uma linguagem compilada. O código é transformado em um executável antes de ser rodado. 


go run main.go

O comando acima compila e executa o programa diretamente. 


go build

Esse comando gera um arquivo executável do projeto.

Tipagem

Go é estaticamente tipada e fortemente tipada. Isso significa que os tipos são verificados antes da execução e que a linguagem evita misturar tipos incompatíveis sem conversão. 


var nome string = "Gabriel"
var idade int = 20
var ativo bool = true

Go também possui inferência de tipos usando :=. 


nome := "Gabriel"
idade := 20
ativo := true

Variáveis

Em Go, variáveis podem ser declaradas com var ou com declaração curta usando :=. 


var linguagem string = "Go"
versao := 1.22

fmt.Println(linguagem)
fmt.Println(versao)

A declaração curta é muito usada dentro de funções.

Constantes

Constantes armazenam valores que não podem ser alterados durante a execução do programa. 


const pi = 3.14

fmt.Println(pi)

Tipos básicos

int

Representa números inteiros.


idade := 20
fmt.Println(idade)

float64

Representa números decimais.


altura := 1.75
fmt.Println(altura)

string

Representa textos.


nome := "Gabriel"
fmt.Println(nome)

bool

Representa verdadeiro ou falso.


ativo := true
fmt.Println(ativo)

Condicionais

Go usa if e else para tomar decisões. 


idade := 18

if idade >= 18 {
    fmt.Println("Maior de idade")
} else {
    fmt.Println("Menor de idade")
}

Switch

O switch é usado para comparar um valor com vários casos possíveis. 


linguagem := "Go"

switch linguagem {
case "Go":
    fmt.Println("Linguagem eficiente para backend")
case "Python":
    fmt.Println("Linguagem muito usada em dados")
default:
    fmt.Println("Outra linguagem")
}

Em Go, normalmente não é necessário usar break no final de cada caso.

Laços de repetição

Go possui apenas o for como estrutura principal de repetição. Mesmo assim, ele pode ser usado de diferentes formas.

for tradicional


for i := 0; i < 5; i++ {
    fmt.Println(i)
}

for como while


contador := 0

for contador < 5 {
    fmt.Println(contador)
    contador++
}

for infinito


for {
    fmt.Println("Executando")
    break
}

Arrays

Arrays armazenam uma quantidade fixa de valores do mesmo tipo. 


var numeros [3]int

numeros[0] = 10
numeros[1] = 20
numeros[2] = 30

fmt.Println(numeros)

Slices

Slices são mais flexíveis que arrays e são muito mais usados no dia a dia em Go. 


linguagens := []string{"Go", "Python", "Java"}

linguagens = append(linguagens, "JavaScript")

fmt.Println(linguagens)

O comando append adiciona novos valores ao slice.

Maps

Maps armazenam dados no formato chave e valor. 


usuario := map[string]string{
    "nome": "Gabriel",
    "email": "gabriel@email.com",
}

fmt.Println(usuario["nome"])

Funções

Funções são blocos de código reutilizáveis. Em Go, usamos a palavra-chave func. 


func somar(a int, b int) int {
    return a + b
}

func main() {
    resultado := somar(5, 3)

    fmt.Println(resultado)
}

Múltiplos retornos

Go permite que uma função retorne mais de um valor. Isso é muito usado para retornar resultado e erro. 


func dividir(a float64, b float64) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("divisão por zero")
    }

    return a / b, nil
}

Tratamento de erros

Em Go, erros normalmente são tratados de forma explícita. Em vez de usar exceções como em algumas linguagens, Go costuma retornar um valor de erro. 


resultado, err := dividir(10, 0)

if err != nil {
    fmt.Println("Erro:", err)
    return
}

fmt.Println(resultado)

Essa abordagem deixa o tratamento de erro bem visível no código.

Structs

Structs são usadas para criar tipos personalizados agrupando campos. 


type Usuario struct {
    Nome  string
    Idade int
}

func main() {
    usuario := Usuario{
        Nome:  "Gabriel",
        Idade: 20,
    }

    fmt.Println(usuario.Nome)
}

Métodos

Go permite criar métodos associados a tipos, como structs. 


type Usuario struct {
    Nome string
}

func (u Usuario) Apresentar() {
    fmt.Println("Meu nome é", u.Nome)
}

func main() {
    usuario := Usuario{Nome: "Gabriel"}

    usuario.Apresentar()
}

Ponteiros

Ponteiros armazenam o endereço de memória de uma variável. Go permite usar ponteiros, mas de forma mais simples e segura que C. 


idade := 20
ponteiro := &idade

fmt.Println(ponteiro)
fmt.Println(*ponteiro)

O símbolo & pega o endereço da variável. O símbolo * acessa o valor apontado.

Interfaces

Interfaces definem comportamentos. Um tipo implementa uma interface automaticamente quando possui os métodos exigidos por ela. 


type Apresentavel interface {
    Apresentar()
}

type Usuario struct {
    Nome string
}

func (u Usuario) Apresentar() {
    fmt.Println("Meu nome é", u.Nome)
}

Goroutines

Goroutines são uma das principais características de Go. Elas permitem executar funções de forma concorrente, ou seja, ao mesmo tempo em relação ao fluxo principal do programa. 


func mostrarMensagem() {
    fmt.Println("Executando em goroutine")
}

func main() {
    go mostrarMensagem()

    fmt.Println("Programa principal")
}

A palavra-chave go inicia uma goroutine.

Channels

Channels permitem comunicação entre goroutines. 


canal := make(chan string)

go func() {
    canal <- "Mensagem da goroutine"
}()

mensagem := <-canal

fmt.Println(mensagem)

Channels são importantes para coordenar tarefas concorrentes em Go.

Pacotes

Pacotes ajudam a organizar o código em Go. Todo arquivo Go começa com a declaração de pacote. 


package main

O pacote main é usado para criar programas executáveis.

Go Modules

Go Modules é o sistema usado para gerenciar dependências em projetos Go. 


go mod init meu-projeto

Esse comando cria o arquivo go.mod, que identifica o módulo do projeto e suas dependências.

Go no backend

Go é muito usado no backend por ser rápido, simples e eficiente para lidar com muitas requisições. 


package main

import (
    "fmt"
    "net/http"
)

func home(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintln(w, "API funcionando")
}

func main() {
    http.HandleFunc("/", home)
    http.ListenAndServe(":8080", nil)
}

  • Ferramentas oficiais boas

Desvantagens do Go

  • Sintaxe simples pode parecer limitada para alguns casos
  • Tratamento de erros pode ficar repetitivo
  • Não é tão indicada para front-end no navegador
  • Menos flexível que linguagens muito expressivas
  • Alguns recursos modernos são mais simples do que em outras linguagens

Boas práticas em Go

  • Manter código simples e direto
  • Tratar erros explicitamente
  • Usar nomes claros
  • Organizar código em pacotes
  • Evitar abstrações desnecessárias
  • Usar gofmt para formatar o código
  • Usar goroutines com cuidado
  • Não ignorar erros retornados por funções

Erros comuns de iniciantes

Ignorar erros

Em Go, muitos erros são retornados por funções. Ignorá-los pode causar problemas difíceis de identificar.

Confundir array com slice

Arrays têm tamanho fixo. Slices são mais flexíveis e usados com mais frequência.

Usar goroutines sem controle

Criar goroutines sem coordenação pode gerar problemas de concorrência.

Não entender ponteiros

Ponteiros são úteis em Go, mas precisam ser entendidos para evitar confusão.

Exemplo simples em Go


package main

import "fmt"

type Usuario struct {
    Nome  string
    Idade int
}

func verificarIdade(idade int) string {
    if idade >= 18 {
        return "Maior de idade"
    }

    return "Menor de idade"
}

func main() {
    usuario := Usuario{
        Nome:  "Gabriel",
        Idade: 20,
    }

    linguagens := []string{"Go", "Python", "Java"}

    fmt.Println("Nome:", usuario.Nome)
    fmt.Println("Idade:", usuario.Idade)
    fmt.Println(verificarIdade(usuario.Idade))

    fmt.Println("Linguagens:")

    for _, linguagem := range linguagens {
        fmt.Println(linguagem)
    }
}

Dúvidas comuns sobre Go

Go é bom para iniciantes?

Sim. Go tem uma sintaxe simples, mas alguns conceitos como ponteiros, goroutines e channels podem exigir prática.

Go serve para backend?

Sim. Go é muito usado em backend, APIs, microsserviços e sistemas de alta performance.

Go é melhor que Python?

Depende do objetivo. Go costuma ter melhor desempenho e gerar executáveis mais eficientes. Python costuma ser mais simples para prototipagem, automação e dados.

Go usa orientação a objetos?

Go não usa classes como Java ou C#, mas possui structs, métodos e interfaces, permitindo organizar código de forma parecida em alguns aspectos.

Vale a pena aprender Go?

Sim, principalmente para quem quer trabalhar com backend, cloud, infraestrutura, microsserviços, DevOps ou sistemas distribuídos.

Resumo

Go é uma linguagem simples, rápida e eficiente, criada para resolver problemas modernos de backend, infraestrutura e sistemas distribuídos.

Seus principais conceitos incluem variáveis, tipos, funções, structs, slices, maps, interfaces, ponteiros, goroutines, channels, pacotes e tratamento explícito de erros.
