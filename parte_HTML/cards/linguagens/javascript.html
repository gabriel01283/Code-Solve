JavaScript

JavaScript é uma linguagem de programação essencial para o desenvolvimento web. Ela é usada principalmente para adicionar interatividade, lógica e comportamento às páginas da internet.

Enquanto HTML estrutura o conteúdo e CSS define o visual, JavaScript permite criar ações dinâmicas, como cliques em botões, validação de formulários, menus interativos, consumo de APIs, animações e atualização de conteúdo sem recarregar a página.

Além do navegador, JavaScript também pode ser usado no backend com Node.js, tornando a linguagem uma das mais versáteis do desenvolvimento moderno.

O que é JavaScript?

JavaScript é uma linguagem de programação de alto nível, interpretada, dinamicamente tipada e multiparadigma.

Ela foi criada para rodar nos navegadores, mas hoje também é usada em servidores, aplicações desktop, aplicações mobile, automações e ferramentas de desenvolvimento. 


console.log("Olá, mundo!");

Para que serve JavaScript?

  • Adicionar interatividade em páginas web
  • Manipular elementos HTML
  • Validar formulários
  • Consumir APIs
  • Criar aplicações front-end
  • Criar back-end com Node.js
  • Desenvolver aplicações em tempo real
  • Criar interfaces dinâmicas
  • Trabalhar com eventos do usuário

Tipagem

JavaScript é dinamicamente tipado. Isso significa que o tipo de uma variável é definido durante a execução, de acordo com o valor armazenado. 


let nome = "Gabriel";
let idade = 20;
let ativo = true;

A mesma variável pode receber valores de tipos diferentes, embora isso deva ser usado com cuidado para evitar confusão no código.

Variáveis

Em JavaScript, usamos principalmente let e const para declarar variáveis.

let

Usado quando o valor pode mudar.


let idade = 20;
idade = 21;

console.log(idade);

const

Usado quando o valor não deve ser reatribuído.


const nome = "Gabriel";

console.log(nome);

Tipos principais

String

Representa textos.


const nome = "Gabriel";

Number

Representa números inteiros e decimais.


const idade = 20;
const altura = 1.75;

Boolean

Representa verdadeiro ou falso.


const ativo = true;

Null

Representa ausência intencional de valor.


const usuario = null;

Undefined

Representa uma variável sem valor definido.


let resultado;

console.log(resultado);

Object

Representa uma estrutura com propriedades e valores.


const usuario = {
    nome: "Gabriel",
    idade: 20
};

Arrays

Arrays armazenam vários valores em uma única variável. 


const linguagens = ["JavaScript", "Python", "Java"];

console.log(linguagens[0]);

O primeiro item de um array fica na posição zero. 


linguagens.push("C++");

console.log(linguagens);

Objetos

Objetos são usados para representar entidades com propriedades. 


const usuario = {
    nome: "Gabriel",
    idade: 20,
    email: "gabriel@email.com"
};

console.log(usuario.nome);

Funções

Funções são blocos de código reutilizáveis. 


function somar(a, b) {
    return a + b;
}

const resultado = somar(5, 3);

console.log(resultado);

Arrow functions

Arrow functions são uma forma mais curta de escrever funções. 


const somar = (a, b) => {
    return a + b;
};

console.log(somar(5, 3));

Quando a função tem apenas uma expressão, pode ser ainda mais curta. 


const multiplicar = (a, b) => a * b;

Condicionais

Condicionais permitem executar código dependendo de uma condição. 


const idade = 18;

if (idade >= 18) {
    console.log("Maior de idade");
} else {
    console.log("Menor de idade");
}

Switch

O switch é usado para comparar um valor com vários casos possíveis. 


const linguagem = "JavaScript";

switch (linguagem) {
    case "JavaScript":
        console.log("Linguagem da web");
        break;

    case "Python":
        console.log("Linguagem muito usada em dados");
        break;

    default:
        console.log("Outra linguagem");
}

Laços de repetição

for


for (let i = 0; i < 5; i++) {
    console.log(i);
}

while


let contador = 0;

while (contador < 5) {
    console.log(contador);
    contador++;
}

forEach


const linguagens = ["JS", "Python", "Java"];

linguagens.forEach((linguagem) => {
    console.log(linguagem);
});

DOM

DOM significa Document Object Model. Ele representa a estrutura HTML da página como objetos que podem ser acessados e modificados pelo JavaScript. 


const titulo = document.querySelector("h1");

titulo.textContent = "Novo título";

Com o DOM, é possível alterar textos, estilos, classes, atributos e criar novos elementos na página.

Eventos

Eventos são ações que acontecem na página, como cliques, digitação, envio de formulário ou carregamento da tela. 


const botao = document.querySelector("button");

botao.addEventListener("click", () => {
    console.log("Botão clicado");
});

Fetch e APIs

O fetch é usado para fazer requisições HTTP e consumir APIs. 


fetch("https://api.exemplo.com/users")
    .then((response) => response.json())
    .then((data) => {
        console.log(data);
    });

Com fetch, o front-end consegue buscar dados do back-end, enviar formulários, fazer login, carregar comentários e muito mais.

Async e await

Async e await deixam o código assíncrono mais fácil de ler. 


async function carregarUsuarios() {
    const resposta = await fetch("https://api.exemplo.com/users");
    const dados = await resposta.json();

    console.log(dados);
}

carregarUsuarios();

Promises

Promises representam operações que podem terminar no futuro, como uma requisição para uma API. 


const promessa = new Promise((resolve) => {
    resolve("Operação concluída");
});

promessa.then((resultado) => {
    console.log(resultado);
});

JSON

JSON é um formato muito usado para troca de dados entre front-end e back-end. 


const usuario = {
    nome: "Gabriel",
    idade: 20
};

const json = JSON.stringify(usuario);

console.log(json);

Para transformar JSON em objeto JavaScript, usamos JSON.parse.

LocalStorage

LocalStorage permite salvar dados no navegador. 


localStorage.setItem("token", "abc123");

const token = localStorage.getItem("token");

console.log(token);

Ele é muito usado para guardar informações simples, como tokens de autenticação.

JavaScript no front-end

No front-end, JavaScript é usado para manipular páginas, responder a ações do usuário e se comunicar com APIs.

  • Menus interativos
  • Formulários dinâmicos
  • Login e cadastro
  • Validações
  • Comentários
  • Consumo de APIs
  • Alteração de conteúdo sem recarregar a página

JavaScript no backend

Com Node.js, JavaScript também pode ser usado no backend para criar APIs, servidores e sistemas. 


console.log("Servidor usando JavaScript");

Frameworks como Express.js facilitam a criação de rotas, middlewares e APIs REST.

Bibliotecas e frameworks

  • React: criação de interfaces
  • Vue: criação de interfaces progressivas
  • Angular: framework front-end completo
  • Next.js: framework baseado em React
  • Express: framework backend com Node.js
  • NestJS: framework backend estruturado

Vantagens do JavaScript

  • Roda diretamente no navegador
  • Essencial para desenvolvimento web
  • Permite criar páginas interativas
  • Pode ser usado no front-end e no backend
  • Possui grande comunidade
  • Tem muitos frameworks e bibliotecas
  • Integra facilmente com APIs

Desvantagens do JavaScript

  • Tipagem dinâmica pode gerar erros difíceis de perceber
  • Algumas partes da linguagem podem confundir iniciantes
  • Código pode virar bagunça se não for bem organizado
  • Dependência excessiva de bibliotecas pode complicar projetos
  • Comportamentos assíncronos exigem prática

Boas práticas em JavaScript

  • Usar const sempre que o valor não precisar mudar
  • Usar let quando o valor puder mudar
  • Evitar var em códigos modernos
  • Dar nomes claros para variáveis e funções
  • Separar JavaScript em arquivos próprios
  • Evitar código repetido
  • Tratar erros em requisições
  • Usar async e await com cuidado
  • Organizar o código em funções pequenas

Erros comuns de iniciantes

Esquecer o defer no script

Se o JavaScript tentar acessar elementos antes do HTML carregar, pode dar erro. Usar defer ajuda a evitar isso.

Confundir = com == ou ===

O sinal = atribui valor. == compara com conversão. === compara valor e tipo.

Não tratar erro no fetch

Requisições podem falhar. Por isso, é importante usar try/catch ou tratar erros.

Confundir array com objeto

Arrays armazenam listas. Objetos armazenam propriedades com chave e valor.

Exemplo simples em JavaScript


const usuario = {
    nome: "Gabriel",
    idade: 20,
    linguagens: ["JavaScript", "Python", "Java"]
};

function verificarIdade(idade) {
    if (idade >= 18) {
        return "Maior de idade";
    }

    return "Menor de idade";
}

console.log(`Nome: ${usuario.nome}`);
console.log(`Idade: ${usuario.idade}`);
console.log(verificarIdade(usuario.idade));

usuario.linguagens.forEach((linguagem) => {
    console.log(linguagem);
});

Dúvidas comuns sobre JavaScript

JavaScript é a mesma coisa que Java?

Não. JavaScript e Java são linguagens diferentes, com usos, sintaxes e ecossistemas diferentes.

JavaScript é obrigatório para web?

Para páginas interativas, sim. HTML e CSS criam estrutura e visual, mas JavaScript adiciona comportamento.

JavaScript serve para backend?

Sim. Com Node.js, JavaScript pode ser usado para criar APIs e servidores.

JavaScript é bom para iniciantes?

Sim, principalmente para quem quer aprender desenvolvimento web. Mas alguns conceitos, como assíncrono e DOM, exigem prática.

Resumo

JavaScript é a principal linguagem de programação da web. Ela permite criar páginas interativas, consumir APIs, manipular HTML, validar formulários e desenvolver aplicações completas.

Seus principais conceitos incluem variáveis, tipos, arrays, objetos, funções, eventos, DOM, fetch, async/await, JSON e LocalStorage. Para quem deseja trabalhar com desenvolvimento web, JavaScript é indispensável.
