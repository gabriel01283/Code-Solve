Kotlin

Kotlin é uma linguagem de programação moderna, criada para ser segura, produtiva e mais simples de escrever do que linguagens mais verbosas. Ela é muito conhecida por seu uso no desenvolvimento de aplicativos Android, mas também pode ser usada no backend, em aplicações desktop, multiplataforma e até em projetos web.

Uma das principais características do Kotlin é sua integração com Java. Isso significa que projetos Kotlin podem usar bibliotecas Java e também podem conviver com código Java dentro de uma mesma aplicação.

Kotlin foi projetada para reduzir erros comuns, principalmente problemas relacionados a valores nulos, além de oferecer uma sintaxe mais curta, moderna e expressiva.

O que é Kotlin?

Kotlin é uma linguagem de programação de alto nível, estaticamente tipada, multiparadigma e moderna. Ela pode ser usada para criar aplicações Android, sistemas backend, aplicações multiplataforma e outros tipos de software.

Kotlin roda principalmente sobre a JVM, a mesma máquina virtual usada pelo Java. Por isso, ela consegue aproveitar grande parte do ecossistema Java, como bibliotecas, frameworks e ferramentas já existentes.

Além da JVM, Kotlin também possui outras formas de uso, como Kotlin/JS, Kotlin/Native e Kotlin Multiplatform.

Para que serve Kotlin?

Kotlin serve para desenvolver aplicações modernas com menos código repetitivo e mais segurança. Seu uso mais conhecido é no desenvolvimento Android, mas a linguagem também aparece em outras áreas.

  • Aplicativos Android
  • Backend com Spring Boot
  • Backend com Ktor
  • Aplicações multiplataforma
  • Aplicações desktop
  • Projetos que usam JVM
  • APIs REST
  • Sistemas corporativos
  • Compartilhamento de código entre Android e iOS

Nível da linguagem

Kotlin é considerada uma linguagem de alto nível. Isso significa que ela possui uma sintaxe mais próxima da forma humana de pensar e oferece recursos que facilitam a criação de sistemas.

Ela evita muitos detalhes complexos que aparecem em linguagens mais próximas do hardware, permitindo que o desenvolvedor foque mais na lógica da aplicação.

Mesmo sendo de alto nível, Kotlin pode ser usada em sistemas profissionais, aplicações grandes e projetos que exigem organização, segurança e manutenção.

Kotlin é compilada ou interpretada?

Kotlin é uma linguagem compilada. Na maioria dos casos, o código Kotlin é compilado para bytecode da JVM, que depois é executado pela máquina virtual Java.

Isso permite que Kotlin funcione bem com projetos Java e aproveite bibliotecas do ecossistema JVM. 


fun main() {
    println("Olá, mundo!")
}

A função main é o ponto inicial de execução de um programa Kotlin. A função println imprime uma mensagem na tela.

Tipagem

Kotlin é uma linguagem estaticamente tipada e fortemente tipada.

Ser estaticamente tipada significa que os tipos são verificados antes da execução do programa. Isso ajuda a encontrar erros ainda durante a compilação.

Ser fortemente tipada significa que Kotlin evita misturar tipos incompatíveis de forma perigosa.

Kotlin também possui inferência de tipos. Em muitos casos, o compilador consegue descobrir o tipo automaticamente. 


val nome = "Gabriel"
val idade = 20
val altura = 1.75
val ativo = true

val e var

Em Kotlin, usamos val para valores que não podem ser alterados e var para valores que podem mudar.

val

O val cria uma variável somente leitura. Depois que recebe um valor, ela não pode ser reatribuída. 


val nome = "Gabriel"
println(nome)

var

O var cria uma variável que pode ser modificada. 


var idade = 20
idade = 21

println(idade)

Uma boa prática em Kotlin é usar val sempre que possível e usar var apenas quando o valor realmente precisar mudar.

Tipos básicos

Int

Representa números inteiros. 


val idade: Int = 20
println(idade)

Double

Representa números com casas decimais e maior precisão. 


val altura: Double = 1.75
println(altura)

Float

Também representa números decimais, mas com menor precisão que Double. 


val preco: Float = 19.99f
println(preco)

Boolean

Representa valores verdadeiro ou falso. 


val ativo: Boolean = true
println(ativo)

Char

Representa um único caractere. 


val letra: Char = 'A'
println(letra)

String

Representa textos. 


val linguagem: String = "Kotlin"
println(linguagem)

Strings em Kotlin

Strings são usadas para armazenar textos. Kotlin permite juntar textos e também inserir variáveis dentro de uma string. 


val nome = "Gabriel"
val linguagem = "Kotlin"

println(nome + " está estudando " + linguagem)

A forma mais comum e elegante é usar interpolação de strings. 


val nome = "Gabriel"
val idade = 20

println("Meu nome é $nome e tenho $idade anos.")

Para expressões maiores, usamos chaves. 


val a = 5
val b = 3

println("A soma é ${a + b}")

Null Safety

Um dos recursos mais importantes do Kotlin é o Null Safety. Ele ajuda a evitar erros causados por valores nulos.

Por padrão, uma variável Kotlin não pode receber null. 


val nome: String = "Gabriel"

Para permitir que uma variável receba null, usamos o símbolo ?. 


var email: String? = null

Isso deixa claro no código que aquele valor pode existir ou não.

Safe call

O operador ?. permite acessar um valor apenas se ele não for null. Isso evita erros durante a execução. 


var nome: String? = "Gabriel"

println(nome?.length)

Se nome for null, o programa não quebra. Ele apenas retorna null para aquela operação.

Operador Elvis

O operador Elvis ?: permite definir um valor padrão quando uma variável for null. 


var nome: String? = null

val nomeFinal = nome ?: "Nome não informado"

println(nomeFinal)

Nesse exemplo, como nome está null, a variável nomeFinal recebe o texto "Nome não informado".

Funções

Funções são blocos de código reutilizáveis. Em Kotlin, elas são criadas usando a palavra-chave fun. 


fun somar(a: Int, b: Int): Int {
    return a + b
}

fun main() {
    val resultado = somar(5, 3)
    println(resultado)
}

A função acima recebe dois números inteiros e retorna a soma.

Função de uma linha

Kotlin permite criar funções mais curtas quando a lógica é simples. 


fun somar(a: Int, b: Int): Int = a + b

Esse recurso ajuda a deixar o código mais direto e legível.

Condicionais

Kotlin usa if e else para executar código dependendo de uma condição. 


val idade = 18

if (idade >= 18) {
    println("Maior de idade")
} else {
    println("Menor de idade")
}

Em Kotlin, o if também pode retornar valor. 


val resultado = if (idade >= 18) {
    "Maior de idade"
} else {
    "Menor de idade"
}

println(resultado)

when

O when é parecido com o switch de outras linguagens, mas mais poderoso e expressivo. 


val linguagem = "Kotlin"

when (linguagem) {
    "Kotlin" -> println("Linguagem moderna para Android")
    "Java" -> println("Linguagem muito usada na JVM")
    "Python" -> println("Linguagem simples e versátil")
    else -> println("Outra linguagem")
}

O when é muito usado para tratar múltiplas possibilidades de forma organizada.

Laços de repetição

Laços de repetição permitem executar um bloco de código várias vezes.

for


for (numero in 1..5) {
    println(numero)
}

while


var contador = 0

while (contador < 5) {
    println(contador)
    contador++
}

do while


var numero = 0

do {
    println(numero)
    numero++
} while (numero < 5)

Listas

Listas armazenam vários valores em uma única estrutura. Kotlin possui listas imutáveis e mutáveis.

Lista imutável


val linguagens = listOf("Kotlin", "Java", "Python")

println(linguagens[0])

Lista mutável


val linguagens = mutableListOf("Kotlin", "Java")

linguagens.add("Python")

println(linguagens)

Maps

Maps armazenam dados no formato chave e valor. Eles são úteis para representar informações associadas. 


val usuario = mapOf(
    "nome" to "Gabriel",
    "email" to "gabriel@email.com"
)

println(usuario["nome"])

Nesse exemplo, a chave nome está associada ao valor Gabriel.

Classes

Kotlin suporta programação orientada a objetos. Classes são modelos usados para criar objetos. 


class Usuario(val nome: String, val idade: Int)

fun main() {
    val usuario = Usuario("Gabriel", 20)

    println(usuario.nome)
    println(usuario.idade)
}

Kotlin permite criar classes com menos código quando comparado a linguagens mais verbosas.

Data class

Data classes são usadas para representar dados. Elas geram automaticamente recursos úteis, como toString, comparação e cópia de objetos. 


data class Usuario(
    val nome: String,
    val idade: Int
)

fun main() {
    val usuario = Usuario("Gabriel", 20)

    println(usuario)
}

Data classes são muito comuns em aplicações Kotlin, principalmente para representar respostas de APIs, modelos e informações do sistema.

object

A palavra-chave object permite criar um objeto único. Esse recurso é parecido com a ideia de Singleton. 


object Configuracao {
    val apiUrl = "https://exemplo.com"
}

fun main() {
    println(Configuracao.apiUrl)
}

Isso é útil para configurações, utilitários e objetos que devem existir apenas uma vez na aplicação.

Companion object

Companion object permite criar membros associados à classe, sem precisar criar um objeto da classe para acessá-los. 


class Usuario {
    companion object {
        fun criarVisitante(): String {
            return "Visitante"
        }
    }
}

fun main() {
    println(Usuario.criarVisitante())
}

Interfaces

Interfaces definem comportamentos que uma classe deve implementar. Elas ajudam a organizar contratos dentro do código. 


interface Apresentavel {
    fun apresentar()
}

class Aluno(val nome: String) : Apresentavel {
    override fun apresentar() {
        println("Meu nome é $nome")
    }
}

Extension functions

Extension functions permitem adicionar funções a tipos já existentes sem modificar diretamente a classe original. 


fun String.saudacao(): String {
    return "Olá, $this"
}

fun main() {
    val nome = "Gabriel"

    println(nome.saudacao())
}

Esse recurso deixa o código mais expressivo e é muito usado no ecossistema Kotlin.

Coroutines

Coroutines são um recurso do Kotlin usado para programação assíncrona. Elas ajudam a executar tarefas demoradas sem travar a aplicação.

Em aplicativos Android, por exemplo, coroutines podem ser usadas para buscar dados de uma API, acessar banco de dados ou executar tarefas em segundo plano. 


suspend fun buscarDados() {
    println("Buscando dados...")
}

A palavra-chave suspend indica que a função pode ser pausada e retomada depois.

Kotlin no Android

Kotlin é muito usado no desenvolvimento Android. Ele permite criar aplicativos modernos com uma sintaxe mais limpa e segura.

No Android, Kotlin pode ser usado com XML para interfaces tradicionais ou com Jetpack Compose, uma ferramenta moderna para construir telas de forma declarativa.

Muitas aplicações Android atuais usam Kotlin por causa da produtividade, segurança contra null e boa integração com as ferramentas do Android Studio.

Jetpack Compose

Jetpack Compose é uma ferramenta moderna para criar interfaces Android usando Kotlin. Com ele, o desenvolvedor descreve a interface usando código Kotlin. 


@Composable
fun Saudacao() {
    Text("Olá, Kotlin!")
}

Esse modelo facilita a criação de interfaces reativas e modernas.

Kotlin no backend

Kotlin também pode ser usado no backend, principalmente com frameworks como Spring Boot e Ktor.

Como Kotlin roda na JVM, ele consegue aproveitar o ecossistema Java, que é muito usado em sistemas corporativos, APIs e aplicações de grande porte. 


fun main() {
    println("Backend com Kotlin")
}

Kotlin Multiplatform

Kotlin Multiplatform permite compartilhar partes do código entre diferentes plataformas, como Android, iOS, web e desktop.

A ideia não é necessariamente criar uma única interface para todos os sistemas, mas sim compartilhar regras de negócio, modelos, validações e lógica comum.

Isso pode reduzir repetição de código e facilitar a manutenção de projetos que precisam funcionar em várias plataformas.

Kotlin e Java

Kotlin possui forte interoperabilidade com Java. Isso significa que código Kotlin pode usar classes Java, e código Java pode usar classes Kotlin.

Essa compatibilidade é uma das razões pelas quais Kotlin se tornou tão popular, principalmente em projetos Android e sistemas que já usavam Java.

  • Kotlin roda na JVM
  • Kotlin pode usar bibliotecas Java
  • Projetos podem misturar Kotlin e Java
  • Kotlin reduz bastante código repetitivo comum em Java

Boas práticas em Kotlin

Escrever Kotlin de forma organizada ajuda a manter o código limpo, seguro e fácil de evoluir.

  • Usar val sempre que o valor não precisar mudar
  • Usar var apenas quando for necessário alterar o valor
  • Evitar usar !! sem necessidade
  • Usar safe call e operador Elvis para lidar com null
  • Dar nomes claros para variáveis, funções e classes
  • Usar data class para representar dados
  • Separar responsabilidades em arquivos e classes diferentes
  • Evitar funções muito grandes
  • Usar coroutines corretamente em tarefas assíncronas

Erros comuns de iniciantes

Confundir val e var

Muitos iniciantes usam var para tudo, mas o ideal é usar val quando o valor não precisa mudar.

Usar !! sem cuidado

O operador !! força o acesso a um valor que pode ser null. Se o valor for null, o programa pode quebrar.

Não entender Null Safety

Null Safety é um dos pontos mais importantes do Kotlin. Ignorar esse conceito pode gerar confusão e erros.

Confundir listOf com mutableListOf

listOf cria uma lista imutável. mutableListOf cria uma lista que pode ser alterada.

Trazer hábitos ruins do Java

Kotlin permite escrever código mais curto e expressivo. Copiar exatamente o estilo Java pode deixar o código mais verboso do que necessário.

Exemplo simples em Kotlin

O exemplo abaixo mostra data class, função, lista, condicional e null safety. 


data class Usuario(
    val nome: String,
    val idade: Int,
    val email: String?
)

fun verificarIdade(idade: Int): String {
    return if (idade >= 18) {
        "Maior de idade"
    } else {
        "Menor de idade"
    }
}

fun main() {
    val usuario = Usuario(
        nome = "Gabriel",
        idade = 20,
        email = "gabriel@email.com"
    )

    val linguagens = listOf("Kotlin", "Java", "Python")

    println("Nome: ${usuario.nome}")
    println("Idade: ${usuario.idade}")
    println("Email: ${usuario.email ?: "Email não informado"}")
    println(verificarIdade(usuario.idade))

    println("Linguagens:")

    for (linguagem in linguagens) {
        println(linguagem)
    }
}

Dúvidas comuns sobre Kotlin

Kotlin é bom para iniciantes?

Kotlin pode ser aprendido por iniciantes, mas costuma ser mais fácil para quem já entende lógica de programação ou já teve contato com Java, JavaScript ou outra linguagem parecida.

Kotlin substitui Java?

Em alguns projetos, principalmente Android, Kotlin pode substituir Java. Porém, Java ainda é muito usado em sistemas corporativos, backend e projetos antigos.

Kotlin serve só para Android?

Não. Kotlin é muito conhecido pelo Android, mas também pode ser usado em backend, aplicações desktop, projetos multiplataforma e sistemas que usam JVM.

Kotlin roda no navegador?

Kotlin pode ser usado em projetos web através de Kotlin/JS, mas JavaScript continua sendo a principal linguagem executada diretamente no navegador.

Kotlin é melhor que Java?

Depende do projeto. Kotlin costuma ser mais moderno, menos verboso e mais seguro contra null. Java possui um ecossistema enorme, muita história e ainda é muito usado no mercado.

Vale a pena aprender Kotlin?

Sim, principalmente para quem deseja trabalhar com desenvolvimento Android, backend na JVM ou aplicações multiplataforma.

Resumo

Kotlin é uma linguagem moderna, segura e expressiva, muito usada no desenvolvimento Android e também presente no backend, em sistemas JVM e em projetos multiplataforma.

Seus principais conceitos incluem val, var, tipos básicos, null safety, funções, condicionais, when, listas, classes, data classes, interfaces, extension functions e coroutines. Por sua integração com Java e sua sintaxe moderna, Kotlin é uma linguagem importante para quem deseja trabalhar com aplicações Android e sistemas modernos.
