C++

C++ é uma linguagem de programação poderosa, criada a partir da linguagem C. Ela é muito usada em sistemas que precisam de alto desempenho, controle de memória e eficiência.

C++ aparece em áreas como jogos, sistemas operacionais, aplicações desktop, motores gráficos, softwares embarcados, computação de alto desempenho, simuladores e sistemas financeiros.

Apesar de ser mais complexa para iniciantes, C++ ensina conceitos importantes sobre memória, tipos, ponteiros, desempenho e estrutura interna dos programas.

O que é C++?

C++ é uma linguagem compilada, estaticamente tipada, fortemente tipada, multiparadigma e de alto desempenho.

Ela permite programar usando diferentes estilos, como programação procedural, programação orientada a objetos e programação genérica. 


#include <iostream>

int main() {
    std::cout << "Olá, mundo!" << std::endl;
    return 0;
}

Nível da linguagem

C++ é considerada uma linguagem de médio nível, porque combina recursos de alto nível com acesso a detalhes mais próximos do hardware.

Isso significa que o programador pode criar abstrações modernas, mas também pode controlar memória, ponteiros e desempenho de forma detalhada.

C++ é compilada ou interpretada?

C++ é uma linguagem compilada. O código precisa ser transformado em um programa executável antes de ser rodado. 


g++ main.cpp -o programa
./programa

O compilador analisa o código, encontra erros e gera um executável.

Tipagem

C++ é estaticamente tipada e fortemente tipada. Isso significa que os tipos das variáveis são verificados durante a compilação. 


std::string nome = "Gabriel";
int idade = 20;
double altura = 1.75;
bool ativo = true;

Variáveis

Variáveis armazenam valores na memória. Em C++, precisamos declarar o tipo antes do nome da variável. 


int idade = 20;
double nota = 9.5;
char letra = 'A';
bool aprovado = true;

Tipos básicos

int

Representa números inteiros.


int idade = 20;
std::cout << idade;

double

Representa números decimais com maior precisão.


double altura = 1.75;
std::cout << altura;

float

Representa números decimais com menor precisão que double.


float preco = 19.99f;
std::cout << preco;

char

Representa um único caractere.


char letra = 'A';
std::cout << letra;

bool

Representa verdadeiro ou falso.


bool ativo = true;
std::cout << ativo;

string

Representa textos.


#include <string>

std::string nome = "Gabriel";
std::cout << nome;

Entrada e saída

Em C++, usamos std::cout para exibir informações e std::cin para receber dados do usuário. 


#include <iostream>
#include <string>

int main() {
    std::string nome;

    std::cout << "Digite seu nome: ";
    std::cin >> nome;

    std::cout << "Olá, " << nome;

    return 0;
}

Condicionais

Condicionais permitem executar blocos diferentes dependendo de uma condição. 


int idade = 18;

if (idade >= 18) {
    std::cout << "Maior de idade";
} else {
    std::cout << "Menor de idade";
}

Switch

O switch compara um valor com várias opções possíveis. 


int opcao = 1;

switch (opcao) {
    case 1:
        std::cout << "Cadastrar";
        break;

    case 2:
        std::cout << "Listar";
        break;

    default:
        std::cout << "Opção inválida";
}

Laços de repetição

for


for (int i = 0; i < 5; i++) {
    std::cout << i << std::endl;
}

while


int contador = 0;

while (contador < 5) {
    std::cout << contador << std::endl;
    contador++;
}

do while


int numero = 0;

do {
    std::cout << numero << std::endl;
    numero++;
} while (numero < 5);

Arrays

Arrays armazenam vários valores do mesmo tipo em uma estrutura de tamanho fixo. 


int numeros[3] = {10, 20, 30};

std::cout << numeros[0];

Vector

Vector é uma estrutura mais flexível que arrays tradicionais. Ele permite adicionar e remover elementos com mais facilidade. 


#include <vector>
#include <iostream>

int main() {
    std::vector<std::string> linguagens;

    linguagens.push_back("C++");
    linguagens.push_back("Python");

    std::cout << linguagens[0];

    return 0;
}

Funções

Funções são blocos de código reutilizáveis. 


int somar(int a, int b) {
    return a + b;
}

int main() {
    int resultado = somar(5, 3);

    std::cout << resultado;

    return 0;
}

Sobrecarga de funções

C++ permite criar funções com o mesmo nome, desde que tenham parâmetros diferentes. 


int somar(int a, int b) {
    return a + b;
}

double somar(double a, double b) {
    return a + b;
}

Ponteiros

Ponteiros são variáveis que armazenam endereços de memória. 


int idade = 20;
int* ponteiro = &idade;

std::cout << ponteiro << std::endl;
std::cout << *ponteiro << std::endl;

O símbolo & pega o endereço da variável. O símbolo * acessa o valor apontado.

Referências

Referências permitem criar outro nome para uma variável existente. 


int idade = 20;
int& referencia = idade;

referencia = 21;

std::cout << idade;

Gerenciamento de memória

C++ permite alocar e liberar memória manualmente. Isso dá muito controle, mas também exige cuidado. 


int* numero = new int(10);

std::cout << *numero;

delete numero;

Se a memória alocada não for liberada, pode ocorrer vazamento de memória.

Smart pointers

Smart pointers ajudam a gerenciar memória automaticamente, reduzindo o risco de vazamentos. 


#include <memory>
#include <iostream>

int main() {
    std::unique_ptr<int> numero = std::make_unique<int>(10);

    std::cout << *numero;

    return 0;
}

Eles são preferidos em C++ moderno quando é necessário trabalhar com memória dinâmica.

Classes e objetos

C++ suporta programação orientada a objetos. Classes são modelos usados para criar objetos. 


class Usuario {
public:
    std::string nome;
    int idade;
};

int main() {
    Usuario usuario;

    usuario.nome = "Gabriel";
    usuario.idade = 20;

    std::cout << usuario.nome;

    return 0;
}

Construtores

Construtores são métodos especiais executados quando um objeto é criado. 


class Usuario {
public:
    std::string nome;
    int idade;

    Usuario(std::string nome, int idade) {
        this->nome = nome;
        this->idade = idade;
    }
};

Encapsulamento

Encapsulamento protege os dados internos de uma classe. 


class Conta {
private:
    double saldo;

public:
    void depositar(double valor) {
        saldo += valor;
    }

    double getSaldo() {
        return saldo;
    }
};

Herança

Herança permite que uma classe reutilize atributos e métodos de outra classe. 


class Pessoa {
public:
    std::string nome;
};

class Aluno : public Pessoa {
public:
    std::string turma;
};

Polimorfismo

Polimorfismo permite que métodos tenham comportamentos diferentes dependendo da classe derivada. 


class Animal {
public:
    virtual void emitirSom() {
        std::cout << "Som genérico";
    }
};

class Cachorro : public Animal {
public:
    void emitirSom() override {
        std::cout << "Latido";
    }
};

Structs

Structs em C++ são parecidas com classes, mas seus membros são públicos por padrão. 


struct Produto {
    std::string nome;
    double preco;
};

Templates

Templates permitem escrever código genérico que funciona com diferentes tipos. 


template <typename T>
T maior(T a, T b) {
    return a > b ? a : b;
}

STL

STL significa Standard Template Library. Ela oferece estruturas e algoritmos prontos para usar em C++.

  • vector
  • map
  • set
  • queue
  • stack
  • sort
  • find

Tratamento de exceções

C++ permite tratar erros usando try, catch e throw. 


try {
    throw std::runtime_error("Erro no programa");
} catch (const std::exception& erro) {
    std::cout << erro.what();
}

Boas práticas em C++

  • Usar nomes claros para variáveis, funções e classes
  • Evitar ponteiros crus quando smart pointers forem melhores
  • Inicializar variáveis antes de usar
  • Evitar vazamento de memória
  • Separar código em arquivos .h e .cpp em projetos maiores
  • Usar STL quando fizer sentido
  • Evitar funções muito grandes
  • Tratar erros corretamente

Erros comuns de iniciantes

Esquecer ponto e vírgula

Em C++, muitas instruções precisam terminar com ponto e vírgula.

Usar variável não inicializada

Variáveis sem valor inicial podem gerar comportamentos inesperados.

Confundir ponteiro com valor

Ponteiro guarda endereço. O valor apontado é acessado com o operador *.

Esquecer delete

Quando se usa new, é necessário liberar memória com delete, ou usar smart pointers.

Exemplo simples em C++


#include <iostream>
#include <string>
#include <vector>

class Usuario {
private:
    std::string nome;
    int idade;

public:
    Usuario(std::string nome, int idade) {
        this->nome = nome;
        this->idade = idade;
    }

    std::string verificarIdade() {
        if (idade >= 18) {
            return "Maior de idade";
        }

        return "Menor de idade";
    }

    void apresentar() {
        std::cout << "Nome: " << nome << std::endl;
        std::cout << "Idade: " << idade << std::endl;
        std::cout << verificarIdade() << std::endl;
    }
};

int main() {
    Usuario usuario("Gabriel", 20);

    std::vector<std::string> linguagens = {"C++", "Java", "Python"};

    usuario.apresentar();

    std::cout << "Linguagens:" << std::endl;

    for (std::string linguagem : linguagens) {
        std::cout << linguagem << std::endl;
    }

    return 0;
}

Dúvidas comuns sobre C++

C++ é bom para iniciantes?

Pode ser aprendido por iniciantes, mas costuma ser mais difícil que Python ou JavaScript por causa de ponteiros, memória e detalhes da linguagem.

C++ é igual a C?

Não. C++ foi criado a partir de C, mas adiciona recursos como classes, objetos, templates e outras ferramentas modernas.

C++ ainda é usado?

Sim. C++ continua muito usado em jogos, sistemas, motores gráficos, softwares embarcados e aplicações de alto desempenho.

C++ serve para backend?

Pode ser usado, mas não é tão comum para backend web quanto Java, C#, Go, Python ou JavaScript.

Vale a pena aprender C++?

Sim, principalmente para quem quer entender desempenho, memória, jogos, sistemas, computação gráfica ou programação de baixo nível.

Resumo

C++ é uma linguagem poderosa, rápida e muito usada em sistemas que exigem desempenho e controle. Ela permite trabalhar com memória, ponteiros, orientação a objetos, templates e estruturas eficientes.

Seus principais conceitos incluem variáveis, tipos, entrada e saída, condicionais, loops, arrays, vectors, funções, ponteiros, referências, classes, construtores, encapsulamento, herança, polimorfismo, templates, STL e gerenciamento de memória.
